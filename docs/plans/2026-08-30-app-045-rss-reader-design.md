# App 045 RSS 阅读器设计

## 产品定位

`DIAL/45 频道调谐台` 是一款本地优先的 RSS/Atom 阅读器，面向同时关注多个博客、产品更新和独立刊物的人。页面的单一核心任务是：把散落的更新调到同一条时间线上，让用户快速找出未读信号。

应用运行在 GitHub Pages。订阅、文章与已读状态保存在当前浏览器，不需要账号。首次打开提供三个演示频道和完整文章数据，用户也可以添加支持浏览器跨域读取的真实 RSS/Atom 地址。

## 架构选择与跨域边界

1. **静态本地优先（采用）**：直接请求允许 CORS 的订阅源；内置演示数据保证完整体验。零部署，但无法读取拒绝跨域访问的站点。
2. **公共 CORS 代理**：覆盖更多订阅源，但会把订阅地址交给第三方，并引入不可控的稳定性与隐私风险。
3. **自建代理服务**：能力最完整，但需要额外后端、缓存与滥用防护，不符合本应用直接部署 Pages 的目标。

刷新失败时保留订阅，显示“源未开放跨域读取”或具体网络错误，并允许重试。应用不会偷偷切换到第三方代理，也不会把失败显示成成功。

## 功能范围

- 三个内置演示频道与聚合文章时间线。
- 添加自定义 RSS/Atom URL，可填写频道名并选择频道色。
- 频道启用/停用、选择、刷新和本地删除确认。
- 直接获取并解析常见 RSS 2.0 与 Atom 字段。
- 全部 / 未读 / 已读筛选、标题与摘要搜索、按频道过滤。
- 单篇标记已读/未读，以及将当前可见文章全部标为已读。
- 最多保留 40 个订阅、300 篇文章。
- 当前浏览器持久化，损坏存储安全回退。

不做全文抓取、第三方代理、账号同步、通知、收藏和内容推荐。

## 数据模型

订阅包含：`id`、`title`、`url`、`color`、`enabled`、`builtin`、`createdAt`、`lastFetchedAt`、`status`、`error`。

文章包含：`id`、`feedId`、`title`、`url`、`summary`、`publishedAt`、`fetchedAt`、`read`。

- URL 仅接受 `http:` 与 `https:`，输出链接始终使用 `noopener noreferrer`。
- RSS 中的 HTML 先转换为纯文本，再通过 `textContent` 渲染。
- 合并按文章 ID 幂等；同一文章保留新的内容与本地已读状态。
- 订阅停用后文章仍保留，但从“所有启用频道”聚合中隐藏。
- 删除自定义频道会同时删除其文章；内置频道不能删除。

## 视觉系统

主题不是报纸或资讯后台，而是一台浅色广播调谐仪器。

- **机壳蓝** `#243B6B`：结构、标题与按钮。
- **刻度纸** `#EEF2D7`：页面主背景。
- **信号橙** `#F06449`：未读与主要操作。
- **波段青** `#50AFA4`：正常连接状态。
- **刻度黄** `#F1C75B`：调谐指针与焦点。
- **石墨灰** `#353A49`：正文。

展示字使用宽重系统黑体模拟设备铭牌，正文使用中文无衬线，频率、时间和状态使用等宽字体。唯一高强度视觉记忆点是一条横跨页面的调谐刻度：选择频道时指针移动到对应预设位，刻度下方显示频道色和未读数量。

## 布局

```text
┌ DIAL/45 ─ 搜索 ─ 刷新信号 ┐
│ 把散落的更新，调到同一条频率 │
│ 88 ━━━━│━━━━ 108 MHz       │
├ 频道预设 ──────┬ 信号记录 ───┤
│ 全部频道        │ [全部][未读] │
│ 设计波段   4    │ 文章标题      │
│ 技术波段   2    │ 摘要 / 时间   │
│ + 添加频道      │ 标记已读      │
└ 本地保存 / 数据边界 / 统计 ───┘
```

桌面端左侧为频道预设台，右侧为文章流；窄屏下频道变成横向预设条。键盘焦点明确，指针动画服从系统减少动态效果设置。

## 验证标准

- 核心测试覆盖 URL、订阅与文章规范化、幂等合并、容量裁剪、已读切换、筛选和统计。
- 浏览器验证添加本地示例 RSS、XML 解析、频道选择、搜索、已读/未读、批量已读、停用、删除确认和刷新持久化。
- 验证无效 XML 与 CORS/网络错误有明确状态，不破坏已有文章。
- 检查纯文本安全、链接协议、控制台、响应式规则和追踪器 45/100。
