# ✅ #003 待办清单 · TodoList

> 经典入门应用：增删改查 + 完成度进度条 + 三态筛选，数据本地持久化，刷新不丢。

## ✨ 功能

- 添加任务（回车或按钮）、圆圈点击切换完成、悬停删除
- 全部 / 未完成 / 已完成 三态筛选
- 完成度进度条 + 剩余数统计，浏览器标签页标题显示未完成数量
- 一键清除已完成
- localStorage 持久化

## 🛠 技术栈

纯 HTML / CSS / JS 单文件，零依赖。

**核心模式——数据驱动渲染**：
- 数据层：`todos` 数组是唯一真相
- 渲染层：`render()` 遍历数据生成 HTML
- 事件层：任何操作都是"改数组 → save() → render()"三步
- 这就是 React `useState` 的手动版，理解了它就理解了现代前端框架的底层逻辑

## 🚀 运行

直接打开 `index.html`，或访问 GitHub Pages。
