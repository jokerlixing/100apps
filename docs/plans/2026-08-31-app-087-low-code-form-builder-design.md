# App 087 · JIG/87 表单装配台设计

## 产品边界

JIG/87 面向需要在几分钟内搭建报名、反馈或申请表的个人与小团队。它的单一任务是：把字段像零件一样装入表单、即时验证结果，并导出可以独立运行的 HTML。项目不提供账号、云端协作、服务端收集或第三方表单投递；所有草稿都只保存在当前浏览器，导出的表单也明确采用本地演示提交。

评估过三种架构：React/Vite 能提升组件工程化，但增加构建与部署负担；Node 服务端能收集真实提交，却引入隐私、账号和运维范围；零依赖静态模块可以直接部署 GitHub Pages，同时通过纯函数测试保证 schema、验证与导出的可靠性。因此采用第三种方案。

## 核心闭环

1. 从零件仓点击或拖入文本、邮箱、数字、长文本、下拉、单选、多选、日期、说明段和分隔标题。
2. 在装配轨上选择、拖拽重排、复制或删除字段；移动端可使用上移和下移按钮。
3. 在校准台修改标签、说明、占位、必填、宽度、选项与数值边界，修改立即反映到表单。
4. 切换到试填模式，填写并校验表单；通过后显示结构化提交回执。
5. 自动保存草稿，可导入/导出 JSON，也可导出带样式、验证和本地回执的独立 HTML。

## 视觉系统

视觉来自工业装配夹具，而不是通用仪表盘。色板为冷轧蓝 `#17324D`、机台灰 `#D7DEE2`、图纸白 `#F5F7F6`、安全橙 `#F05A32`、校准黄 `#F2C94C`、油墨黑 `#17202A`。标题使用 `Bahnschrift SemiCondensed` / `Arial Narrow`，正文使用 `Segoe UI` / `Microsoft YaHei`，尺寸、编号和 schema 使用 `Cascadia Mono` / `Consolas`。

招牌元素是贯穿中间画布的“装配标尺”：字段块沿刻度排列，拖拽时出现真实的卡槽定位线；这个结构同时表达顺序和当前落点，不作为纯装饰。桌面是零件仓、装配轨、校准台三栏；低于 980px 时校准台移到画布下方，低于 680px 时全部单列。触控目标至少 44px，焦点清晰，颜色之外使用文字与图标表达状态，并在 `prefers-reduced-motion` 下取消位移动画。

## 架构与数据流

- `model.js`：字段元数据、schema 清洗、增删改排、表单验证、HTML/JSON 导出和文件名处理，支持浏览器全局与 CommonJS。
- `app.js`：状态、撤销/重做、localStorage、拖放、属性编辑、预览提交和文件下载。
- `index.html` / `styles.css`：语义结构、三栏装配台与响应式视觉。
- schema 版本固定为 `1`。导入时丢弃未知字段、修复重复 ID、限制字段和选项数量；损坏草稿回退到内置示例。

每次用户动作先经模型函数生成新 schema，再写入历史与 localStorage，最后统一渲染。预览值只存在内存，不写入草稿。独立 HTML 导出会转义所有用户内容，不拼接可执行用户脚本。

## 验收与测试

Node 内置测试覆盖默认字段、schema 清洗、ID 去重、增删改排、选项规范、必填/邮箱/数字/多选验证、JSON 往返和独立 HTML 转义。静态检查覆盖唯一 ID、标签关联、无第三方资源和危险内联事件。浏览器冒烟覆盖点击添加、拖拽重排、属性编辑、复制、删除、撤销重做、试填成功/失败、草稿恢复、JSON 导入导出、HTML 导出、1440px 与 390px 布局、无横向溢出、键盘焦点和控制台错误。
