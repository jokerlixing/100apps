# SCAN/46 在线测验系统

100 个应用挑战的第 46 个项目。一个完全运行在浏览器中的本地测验站，提供随机组卷、限时答题、自动保存、即时判分和错题解析。

## 功能

- 24 道内置中文题目，覆盖 Web、科学、逻辑和常识
- 单选、多选、判断三种题型
- 按题量、分类和难度随机组卷
- 5/10/15 分钟限时或不限时模式
- 实时答题进度、题号跳转和页面内交卷确认
- 刷新后恢复未完成答卷，倒计时不会重置
- 自动判分、分类表现、错题/全部题目复盘
- 最近 8 次成绩保存在当前浏览器
- 可通过二次确认安全清空最近成绩
- 响应式布局、键盘操作和 reduced-motion 支持

## 本地运行

在仓库根目录启动静态服务器：

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

然后访问：

```text
http://127.0.0.1:8765/apps/046-online-quiz/
```

## 测试

```powershell
node --test apps/046-online-quiz/quiz-core.test.js
```

项目不依赖第三方库或在线 API。题目、草稿和历史成绩均不会离开浏览器。
