# App 055 JSON 格式化工具设计

## 产品边界

App 055 面向需要快速检查接口响应、配置文件和调试片段的前端开发者。页面只完成一件事：让一段 JSON 从“看不清或解析失败”变成可以定位、理解和带走的结构。首版保持纯前端、零依赖与离线可用，不引入代码编辑器、云端保存、JSON5、Schema 校验或多人协作。输入始终留在当前浏览器中，解析后的内容只在内存里流转；本地草稿仅在体积不超过 250 KB 时自动保存。

核心闭环为输入、校验、整理、探索、导出。用户可以粘贴、拖入或选择 `.json` 文件；有效内容可以按 2 空格或 4 空格格式化、压缩、复制和下载。右侧树形视图支持逐层折叠、全部展开/收起、按键名或值搜索，以及复制任意节点的 JSONPath。无效内容不会只给出浏览器错误文本，而是换算为行号、列号并展示带插入符号的上下文片段。所有用户数据以 `textContent` 渲染，避免把 JSON 字符串解释为 HTML。

## 交互与信息架构

桌面端采用“检验台”双栏：左侧是带行号标尺的原始输入，右侧是结构树和节点路径，中间状态梁显示有效/错误状态。顶部只保留返回挑战、示例、打开文件和清空；与当前内容有关的动作靠近编辑器，避免工具条堆叠。输入经 220ms 防抖自动校验，格式化、压缩、复制和下载仍由明确按钮触发。空输入呈现操作邀请，不计为错误；文件超过 2 MB 或不是文本 JSON 时给出可恢复说明。

键盘用户可以直接 Tab 到每个动作；树节点的展开按钮使用原生 `button` 并同步 `aria-expanded`。搜索结果带匹配计数，回车或“下一个”会把对应节点滚入视图。移动端在 760px 以下改为上下两块，动作区可换行，文本编辑区和树区各自保留稳定高度，不产生页面横向滚动。减少动态效果偏好会关闭状态梁和节点定位动画。

## 视觉方向

主题名为「SPEC/55 数据标本台」，取材于实验室样本标签、工程蓝图和代码行号纸带，而不是常见的黑底霓虹终端。调色板为标本纸 `#edf1f3`、深海墨 `#14242f`、蓝图蓝 `#356aa0`、校验青 `#22a394`、油笔橙 `#e57d35`、结构紫 `#7357a3`。标题使用窄体 `Bahnschrift Condensed`，正文使用 `Segoe UI`，数据与路径使用 `Cascadia Mono`。

页面的签名元素是一条贯穿输入和树形区的“标本脊柱”：左边记录行号，右边记录 `$` 开头的 JSONPath，校验状态像样本章一样压在中间。颜色只表达数据类型和状态，不用无意义渐变；圆角收敛到小尺寸，边框、刻度和夹签承担结构。唯一较大胆的动作是校验成功时状态章沿脊柱短促盖下，失败时则停在精确行号旁，帮助用户把视觉记忆与定位动作联系起来。

## 测试与完成标准

核心模块通过 Node 内置测试覆盖有效/无效解析、CRLF 行列换算、格式化与压缩、深度和节点统计、JSONPath 转义、循环安全防护以及搜索限制。浏览器验证覆盖粘贴、示例、格式化、压缩、复制、下载、文件导入、错误定位、树折叠、搜索定位和草稿恢复。视觉检查至少包含 1280×800 与 390×844 两种视口，确认无横向溢出、焦点清晰、空态与错误态可读、控制台无应用错误。最后更新根追踪器的 55 号链接与完成态，并只把完成代码推送到 GitHub `origin`。
