# POST/44 夜班邮局留言墙

> 一面以邮局分拣台为视觉主题、带弹幕传送带和点赞筛选的本地留言墙。

## 在线地址

<https://jokerlixing.github.io/100apps/apps/044-message-wall/>

## 功能

- 发布 1–120 字纯文本留言，支持署名与 5 种邮戳色
- 两条不同方向、不同速度的弹幕分拣带
- 暂停/继续分拣动画，并尊重系统“减少动态效果”设置
- 点赞与取消点赞
- 全部、高赞、我的留言筛选
- 最多保留 80 条留言
- `localStorage` 刷新持久化
- `BroadcastChannel` 同浏览器多标签实时同步
- 存储损坏或通信通道不可用时安全降级
- 键盘焦点、移动端布局和空状态

## 数据边界

GitHub Pages 是静态托管，不提供共享数据库。用户留言与点赞只保存在当前浏览器；同一站点的标签页可以同步，但其他浏览器和设备看不到这些本地留言。

首次访问会显示 6 条内置示例留言。所有留言使用 `textContent` 渲染，HTML 风格文本只会作为普通文字显示。

## 文件

- `index.html`：页面、交互、持久化和跨标签同步
- `wall-core.js`：清洗、规范化、幂等合并、裁剪、点赞和筛选
- `wall-core.test.js`：Node 自动化测试

## 测试

```bash
node --check wall-core.js
node --test wall-core.test.js
```

测试覆盖：

- 控制字符与空白清理
- HTML 风格文本保持纯文本
- 署名、颜色、点赞数和所有权规范化
- 幂等合并与新版本优先
- 最近 80 条裁剪
- 点赞可逆且不出现负数
- 高赞与我的筛选顺序

## 本地运行

在仓库根目录启动任意静态服务器，例如：

```bash
python -m http.server 8765
```

然后访问：

<http://127.0.0.1:8765/apps/044-message-wall/>
