# #018 天气仪表盘 (Weather Dashboard)

接入 Open-Meteo 免费 API 的实时天气面板：城市搜索 + 当前天气 + 24h 温度曲线 + 7 日预报。

## 功能
- **城市搜索**：中文/英文城市名（geocoding API 自动补全下拉，300ms 防抖）
- **当前天气**：温度/体感/天气描述（emoji 图标，晴天夜晚自动换 🌙）+ 湿度/风速风向/气压/能见度四指标卡
- **24h 温度曲线**：SVG 贝塞尔平滑折线 + 渐变填充 + 最高/最低点标注 + 每 6h 刻度
- **7 日预报**：每日天气图标/描述/最高最低温网格
- **8 个快捷城市**：一键切换（北上广深杭蓉汉西安）
- **城市记忆**：最后查询城市存 localStorage，下次自动加载

## 核心知识点：异步 API 调用链
```
① geocoding API：城市名 → [lat, lon]（支持中文）
② forecast API：[lat, lon] → current + hourly + daily
两级 fetch 串行 → async/await 扁平化书写

竞态防护：reqSeq 请求序号
  快速连续搜索时，旧响应回来先比对序号，过期直接丢弃
  ——防止"搜深圳结果被北京的旧响应覆盖"的经典 bug

防抖 300ms：打字停顿才发请求，省 API 配额
```

## 细节
- WMO 天气码 → 中文+emoji 完整映射表（30+ 种天气）
- 风向 360° → 八方位中文（北/东北/东…）
- 错误兜底：城市找不到/网络失败都有友好提示
- Open-Meteo 免费无密钥，个人用途无需注册
