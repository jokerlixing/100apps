# App 061 每日壁纸设计

## 产品边界

61 号应用命名为 **LUMEN/61**，面向希望每天打开浏览器时先看一眼好风景的用户。页面只完成一件事：浏览最近八天的 Bing 每日图片，并把喜欢的画面保存为个人首页背景。它不假装拥有浏览器或操作系统权限；“设为首页”会把画面固定为本应用首页背景，并提供复制当前页面地址与浏览器设置提示，系统桌面壁纸则通过下载原图后由用户自行设置。

## 数据与降级

应用优先从公开的 Bing Wallpaper API 适配层读取最近八天的图片元数据，逐条请求以保留日期、版权与原图地址。请求设置超时并使用 `Promise.allSettled`，单日失败不会拖垮整组。接口全部失败时展示八张内置精选图片，并明确标注“精选兜底”，不能伪装成当日 Bing 数据。收藏 ID、固定的首页背景 ID 和最近一次成功元数据保存在 localStorage；不保存图片二进制，不申请账号或 API Key。

## 信息架构与交互

桌面端是一张横向“透光片台”：主画面占据首屏，左侧安静地放日期、标题与版权，底部胶片日期刻度负责切换最近八天。右上角只有收藏、下载、设为首页三个主操作。用户可用左右方向键或日期胶片切换，`F` 收藏，画面加载失败时自动回退到该日期的低分辨率/兜底图。收藏抽屉只展示已收藏画面，允许定位或取消收藏；空状态直接引导用户点击星标。移动端将信息叠层下移，日期胶片保持横向滚动，所有触控目标不小于 44px。

## 视觉方向

视觉来自摄影师暗房的透光片，而不是常见的图片卡片墙。色板为冲洗黑 `#10110f`、雾灰 `#d7d7cf`、灯箱白 `#f5f1e8`、安全灯红 `#ff5a43`、曝光黄 `#f3c969` 与冷片蓝 `#6d8fa8`。标题使用 `Arial Narrow`/`Aptos Narrow` 的压缩字形，正文使用 `Segoe UI`，日期和参数使用 `Consolas`。签名元素是首屏底部连续的八格胶片：每格真的对应一天，选中框像放大镜卡在片孔上。唯一的环境动效是图片切换时的短暂“显影”亮度变化，并为 `prefers-reduced-motion` 关闭。

## 验证标准

核心测试覆盖远程数据归一化、日期格式化、去重排序、收藏切换、首页背景选择、缓存合并和恶意/缺失字段。浏览器验证覆盖实时与强制离线两条路径、八日切换、键盘操作、收藏抽屉、刷新后恢复、下载链接、复制首页地址、图片错误回退、1280px 桌面与 390px 手机布局、可见焦点、无横向溢出以及控制台无未处理错误。
