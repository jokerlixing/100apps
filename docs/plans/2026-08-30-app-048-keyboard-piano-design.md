# App 048 · TAPE/48 键盘钢琴设计

## 产品目标

做一台打开即弹的浏览器排练机：电脑键盘、鼠标和触屏都能演奏两组八度，用户可以录下一段即兴、立即回放，并在刷新页面后找回最近一次片段。项目完全运行在本地浏览器，不依赖音频素材、账号或网络 API。

## 核心体验

1. 用户首次按键或点击琴键时安全启动 Web Audio，并立即发声。
2. 两组八度从 C4 到 B5：低八度使用 `Z S X D C V G B H N J M`，高八度使用 `Q 2 W 3 E R 5 T 6 Y 7 U`；页面同时标出映射。
3. 三种音色使用振荡器与包络合成：钢琴、电钢琴、风琴；可调主音量并开启延音。
4. 点击“录制”后，时间轴按实际时间保存每次按下和松开；停止后可以回放、暂停或清空。
5. 最近一次有效录音保存在 localStorage，刷新后仍可回放；空录音不会覆盖已有片段。

## 范围取舍

- 只做两组八度和三种合成音色，不做完整 88 键、MIDI 导入导出或复杂音频工作站。
- 不加载远程音色采样，避免网络依赖和授权问题；声音由 Web Audio 实时合成。
- 录制保存音符事件与演奏参数，不录制麦克风或系统音频。
- 同一电脑键按住时只触发一次音符，释放时结束；窗口失焦会释放全部音符，避免长鸣。

## 视觉方向

主题名为「TAPE/48 排练磁带机」。界面从八十年代便携录音机、纸质谱表与实体琴键取材，而不是通用深色合成器面板。

- 色彩：谱纸白 `#f4f0df`、设备墨蓝 `#182438`、录音红 `#ef5a47`、磁带黄 `#f2c94c`、波形青 `#55c7be`、石墨 `#20252d`。
- 字体：标题使用宽厚的 `Arial Black`，正文使用清晰的系统中文无衬线，时间与键位使用 `Cascadia Mono`。
- 桌面端上方是身份、状态与控制台，下方让真实比例琴键横跨整台设备；移动端控制区纵向堆叠，琴键容器允许横向滚动。
- 记忆点是位于控制台中央的“磁带时间轴”：录制的音符变成不同高度与颜色的磁带片段，回放磁头沿时间推进。
- 动效只用于琴键下压、录音灯和回放磁头，并尊重 `prefers-reduced-motion`。

## 架构与数据流

- `piano-core.js` 负责音符表、键位映射、频率计算、录音事件归一化、时长计算、时间轴布局与持久化数据校验。
- `app.js` 负责 AudioContext、合成器 voice 生命周期、键盘/指针输入、录音状态机、回放调度和 DOM 渲染。
- 所有输入最终汇入 `noteOn(note, source)` 与 `noteOff(note, source)`；同一音符可由多个来源持有，只有最后一个来源释放时才真正停止发声。
- 录音采用相对毫秒时间保存 `on`/`off` 事件；停止时自动补齐仍按住的音符，再经核心函数规范化后保存。
- 回放使用预先排程的 Web Audio 时间，视觉磁头由 `requestAnimationFrame` 驱动；暂停会取消当前调度并保留当前位置。

## 错误与可访问性

- 浏览器不支持 Web Audio 时显示明确提示并禁用演奏/录音控制，页面仍可阅读。
- AudioContext 未获授权或启动失败时在状态区给出再次点击的操作提示，不使用 `alert`。
- 读取到损坏的本地录音时安全忽略；保存失败只影响刷新恢复，不中断当前演奏。
- 琴键使用按钮语义和明确的 `aria-label`，键盘焦点可见；播放状态通过文字和 `aria-live` 同步。
- 页面内所有二次操作使用可撤销/二次点击语义，不调用原生 `confirm`。

## 可验证标准

- Node 单元测试覆盖键位映射、频率、录音规范化、缺失 note-off 补齐、时长、时间轴比例与损坏数据。
- 浏览器验证电脑键盘、点击、触屏语义、音色、音量、延音、录制、停止、回放、暂停、清空和刷新恢复。
- 桌面与手机尺寸无页面级横向溢出；移动端仅琴键轨道允许有意横向滚动。
- 控制台无错误，所有本地资源返回 200，根追踪器显示 48/100 并链接 GitHub Pages。
