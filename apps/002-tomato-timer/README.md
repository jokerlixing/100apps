# 🍅 #002 番茄钟 · Tomato Timer

> 25 分钟专注 + 5 分钟休息的经典番茄工作法计时器，专注/短休/长休自动流转，当日数据统计。

## ✨ 功能

- 专注 / 短休息 / 长休息三模式，完成后自动流转（每 4 个番茄触发长休息）
- 时长预设：15 / 25 / 35 / 45 分钟可切换
- 环形倒计时进度 + 标签页标题同步显示剩余时间
- 当日统计：完成番茄数 / 专注分钟数 / 累计番茄数（localStorage 按日重置）
- 完成提示音（Web Audio 合成，无外部文件）
- 快捷键：`Space` 开始 / 暂停
- 时间戳驱动计时（`endAt - now`），切后台不漂移

## 🛠 技术栈

纯 HTML / CSS / JS，单文件，零依赖。数据存 localStorage。

## 🚀 运行

直接双击 `index.html` 打开，或访问 GitHub Pages（仓库根目录的追踪器里填好本应用链接）。
