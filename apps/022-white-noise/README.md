# #022 白噪音播放器 (White Noise Player)

Web Audio 实时合成的白噪音混音台：10 种声源、5 组场景预设、定时关闭。

## 功能
- **10 种声源**（全部程序化合成，零音频文件）：
  🌧 雨声 · ⛈ 雷雨 · 🌊 海浪 · 🏞 溪流 · 🌲 森林（鸟鸣）
  🔥 篝火（噼啪） · ⬜ 白噪 · 🌸 粉噪 · 🟤 棕噪 · ☕ 咖啡馆
- **多声源混音**：任意组合同时播放，每声源独立音量滑杆
- **5 组场景预设**：助眠/专注/海边/露营/咖啡馆 一键切换
- **定时关闭**：15/30/60 分钟，到点淡出停止
- **主音量控制** + 总开关（渐入渐出防爆音）

## 核心知识点：Web Audio 噪声合成
```
三种噪声色（逐样本生成，ScriptProcessor→BufferSource）：
  白噪 = 均匀随机数（全频等能，"沙沙"）
  粉噪 = Voss-McCartney 算法（1/f 能量，"下雨般的舒适"）
  棕噪 = 白噪积分（1/f²，"远处海啸般低沉"）

声音塑形 = 噪声底 + 滤波器链 + 调制：
  雨声   = 粉噪 + highpass(900Hz) + 随机高频滴答脉冲
  海浪   = 棕噪 + lowpass(600Hz) + LFO(0.11Hz) 音量起伏=潮汐
  森林   = 粉噪 + bandpass(800Hz) + 随机正弦滑音=鸟鸣
  篝火   = 棕噪 + lowpass + 双频段随机爆裂
  雷雨   = 雨声基底 + 4-12秒随机低频轰鸣包络
  咖啡馆 = 粉噪带通 + 偶发杯碟碰撞

随机事件调度器：scheduleRandom(fn, min, max)
  setTimeout 链式自调，每声源停止时 alive=false 终止
```

## 细节
- AudioContext 首次交互创建（浏览器自动播放策略合规）
- 声源切换/停止均 0.3s 淡出（无爆音）
- 预设切换：先清空再应用（380ms 间隔等淡出完成）
- 移动端双列卡片布局

## 技术栈
纯 HTML/CSS/JS 单文件。Web Audio API，零依赖零音频资源。
