# App 060 · PRISM/60 在线图片编辑器设计说明

## 产品目标

PRISM/60 面向需要临时处理配图、封面和社交媒体素材的创作者。页面只做一件事：让用户在不上传图片、不安装软件的情况下，完成导入、裁剪、调色、加字和导出。

图片始终留在当前浏览器中。应用保留原始图像，只记录裁剪范围、滤镜参数和文字参数；预览与导出都由 Canvas 根据这些参数重新渲染。这样可以在保持高分辨率导出的同时支持撤销、重做和一键复原。

## 方案比较

1. **非破坏式 Canvas 配方（采用）**：状态轻、撤销可靠、适合 GitHub Pages，且导出时能从原图重新采样。
2. **逐步改写位图**：代码更短，但连续裁剪和滤镜会不可逆地损失画质，撤销还需要保存大量像素快照。
3. **完整图层编辑器**：可扩展自由绘制、多文字和贴纸，但交互与序列化复杂度远超 60 号项目的核心目标。

## 功能范围

- 拖放、文件选择和剪贴板粘贴 PNG、JPEG、WebP 图片；未导入时提供内置示例画面。
- 自由裁剪与 1:1、4:5、16:9 比例裁剪；裁剪框可移动、可从四角缩放。
- 亮度、对比度、饱和度、灰度、棕褐和模糊细调，并提供原片、暖光、黑白和鲜明预设。
- 添加一层文字，控制内容、字号比例、颜色、横向和纵向位置。
- 撤销、重做、复原，支持常用键盘快捷键。
- 按 50%、75% 或 100% 尺寸导出 PNG、JPEG、WebP；JPEG/WebP 可调质量。

## 视觉方向

界面借用摄影暗房和校色台的语言，而不是通用后台模板。中心画布像一块冷光取景台，左侧是窄工具轨，右侧是带刻度和数值的参数台，顶部保留文件名、画布尺寸和导出动作。

色彩令牌：暗房黑 `#111820`、工作台蓝灰 `#1B2733`、冷光纸白 `#EAF0F2`、校色青 `#58D6E7`、曝光黄 `#FFD166`、洋红标记 `#FF6B9D`。标题使用 `Bahnschrift Condensed`，正文使用 `Segoe UI Variable`，元数据使用系统等宽字体。

页面的记忆点是一条 RGB 校色轨：红、绿、蓝三段细线沿画布底部排布，并与当前亮度、饱和度和对比度数值呼应。它传达“正在校色”的真实含义，而不是装饰性渐变。

```text
┌ PRISM/60 ─ filename · dimensions ─ undo redo ─ EXPORT ┐
├──────┬───────────────────────────────┬─────────────────┤
│ 工具 │                               │ 裁剪比例        │
│ 裁剪 │        冷光画布 / 裁剪框      │ 滤镜预设        │
│ 调色 │                               │ 参数滑杆        │
│ 文字 │                               │ 文字与导出      │
├──────┴──── R ───── G ───── B ───────┴─────────────────┤
```

桌面采用三栏工作台；窄屏下工具轨变成横向标签，参数台移到画布下方。所有控件有清晰焦点状态，降低动态效果设置下关闭入场动画。

## 数据与错误处理

编辑状态只保存可序列化参数，历史记录最多保留 30 步。原始 `HTMLImageElement` 不进入历史。导入会检查 MIME、20 MB 文件上限和 40 MP 像素上限；不支持的文件会给出可操作的错误消息。导出使用 Blob URL，生成后立即释放，图片不会发往网络。

## 验证

纯函数测试覆盖裁剪比例、嵌套裁剪映射、滤镜字符串、输出尺寸和安全文件名。浏览器验证覆盖示例图、文件导入、四角缩放、比例裁剪、滤镜、文字、撤销/重做、三种格式导出，以及 390 px 与桌面布局。最终运行 Node 测试、JavaScript 语法检查、内部资源检查和 Git 差异检查。
