# App 095 · MUSE/95 设计说明

## 产品定位

MUSE/95 是一个“提示词到作品”的浏览器画室：用户输入中文或英文描述，选择画面风格与比例，应用会在本地生成一幅可下载的程序化艺术作品，并把提示词配方收进画廊。作品可以收藏、筛选和复制提示词，完整覆盖清单要求的“文生图 + 画廊 + 提示词分享”。

GitHub Pages 无后端、无密钥，因此基础模式不伪装成云端扩散模型。应用提供一个确定性的本地提示词解释器：识别城市、海洋、森林、花、夜晚、日落等意象，映射调色与构图，再由 Canvas 生成有层次的成品。仓库另包含一张由内置 imagegen 工具生成的原创主展品，明确标为“AI 样片”。未来若接入远程模型，画廊数据结构和呈现层无需改写。

## 方案比较与选择

1. **本地提示词引擎 + 原创 AI 样片（采用）**：无 API Key 也能完整运行、下载和持久化，部署稳定，同时真实展示 AI 生成资产。
2. **浏览器直连付费图像 API**：更接近通用文生图，但需要用户暴露密钥，跨域、计费、接口版本都会影响公开 Demo。
3. **只展示预制画廊**：视觉可控，但用户无法从提示词生成新作品，不满足核心交互。

## 数据与功能

领域核心保存作品的配方而非大体积图片：`id`、`prompt`、`style`、`ratio`、`seed`、`createdAt`、`liked` 和 `source`。Canvas 根据同一配方重复生成相同像素构图；localStorage 只保存最多 18 条用户作品和收藏状态。内置作品不重复落盘。

创作台提供五种风格：梦境拼贴、版画建筑、墨线生长、几何海报、地形光谱；三种比例：方形、竖幅、横幅。提示词经清洗和长度限制后与风格、种子共同生成配方。用户可以“换一组灵感”改变种子、下载 PNG、收藏、复制包含提示词与参数的分享文本。画廊支持全部、我的创作、已收藏筛选和关键词搜索。

错误和空状态都给出下一步：提示词为空时聚焦输入框；浏览器存储失败时作品仍可下载但提示保存失败；剪贴板不可用时使用隐藏文本框回退；画廊筛选无结果时提供清除筛选按钮。

## 视觉方向

主题是“冷色印刷工作室”，避免常见的黑底霓虹 AI 产品。色板为画廊灰 `#E7E9F1`、墨紫 `#211B2D`、皇家紫 `#6552D9`、珊瑚 `#FF735E`、水青 `#B7E5E7`、纸白 `#FBFAFC`。展示字体使用 Bahnschrift SemiCondensed，正文使用 Segoe UI，提示词和配方使用 Cascadia Code。

桌面结构：

```text
┌────────── MUSE/95 / LOCAL STUDIO ──────────────┐
│ 左：大号提示词编辑区      右：本次生成预览       │
│ 风格胶片 / 比例 / 种子     下载 / 收藏 / 分享     │
├────────────────────────────────────────────────┤
│ CURATED + YOUR WORK / 筛选 / 搜索               │
│ 主展品（跨两栏） | 作品卡 | 作品卡 | 作品卡       │
└────────────────────────────────────────────────┘
```

标志性元素是每张作品下方的“提示词校样条”：像印刷打样单一样记录风格、比例、种子和可复制提示词。结构信息是真实配方，而不是装饰编号。唯一大胆动作是主展品跨越画廊网格并叠加一张半透明配方纸，其余区域保持安静、精确。

手机端把创作台改为单列，画布在提示词之后；画廊保持单列大图，筛选横向滚动。所有触控目标至少 44px，焦点清晰，减少动态偏好会关闭生成扫描线和卡片入场。

## 安全与可访问性

- 提示词、搜索、文件名和分享文本均作为文本节点处理，不使用用户 HTML。
- Canvas 绘制不加载用户 URL；内置位图只来自仓库同源路径。
- 下载使用本地 Canvas Blob；无上传、账号、定位、摄像头或密钥。
- 表单字段有可见标签；作品卡使用 `figure`/`figcaption`；生成与复制状态通过 `aria-live` 宣布。
- 样式提供 `:focus-visible`、足够对比度、触控尺寸和 `prefers-reduced-motion`。

## 验收标准

1. 提示词、风格、比例和种子能稳定生成可重复作品，并可 PNG 下载。
2. 新作品进入“我的创作”，刷新后恢复；收藏和筛选状态正确。
3. 每张作品可以复制完整提示词配方，搜索可匹配中文提示词与风格。
4. 原创 AI 主展品从仓库同源加载；断图时卡片仍有清晰占位与配方。
5. 单元测试、语法检查、真实 Chrome 交互、桌面和 390px 手机截图全部通过。
