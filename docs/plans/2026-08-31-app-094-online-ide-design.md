# App #094 在线 IDE 设计

## 产品定位

`BENCH/94 · 浏览器代码实验台` 面向正在学习前端或需要快速验证小段代码的人。页面只做一件事：让用户从 Web、JavaScript、Python 三种实验模式中选择一个模板，编辑代码后在当前浏览器里运行，并立即看到预览、标准输出或错误定位。它是可直接部署到 GitHub Pages 的静态作品集项目，不做账号、多人协作、服务器编译、包管理器、文件系统挂载或任意后端代码执行。

## 方案比较与选择

1. 只做 HTML/CSS/JavaScript 实时预览：完全本地且加载快，但不满足“多语言运行”。
2. 浏览器沙箱 + Web Worker + Pyodide：Web 项目通过受限 iframe 预览，JavaScript 与 Python 在独立 Worker 中运行，适合静态部署。
3. 调用远程多语言编译 API：语言最多，但依赖第三方服务、跨域策略和服务器安全边界。

采用方案 2。Web 模式包含 `index.html`、`styles.css`、`script.js` 三个文件；JavaScript 模式在专用 Worker 中执行；Python 模式按第一次运行时才加载固定版本 Pyodide，并在模块 Worker 中执行。任何运行都可停止，停止时直接终止当前 Worker。Python 首次运行依赖网络下载 WebAssembly 运行时，失败时界面明确说明可重试或切换其他模式。

## 视觉方向

- **主题**：大学机房里的教学机实验台与连续打印纸，而不是通用深色 IDE。
- **色板**：搪瓷蓝 `#C9DDE3`、冷纸白 `#EEF2F0`、终端墨 `#132B32`、运行蓝 `#3157D5`、警示橙 `#ED653F`、通过绿 `#28765F`。
- **字体**：标题使用 `Arial Black / Microsoft YaHei`，正文使用 `Segoe UI / Microsoft YaHei`，代码与状态使用 `Cascadia Code / Consolas`。
- **布局**：桌面端为窄文件轨、宽代码纸、输出窗三段式；手机端先显示模式与文件，再依次显示编辑器、运行操作和结果。
- **标志性元素**：页首“编译纸带”有 `EDIT → CHECK → RUN → RESULT` 四个真实阶段，运行时纸带只移动到当前阶段，成功与失败分别落在绿色或橙色结果章。

```text
┌ BENCH/94 ─ 模式切换 ───────────── 编译纸带 ───────── 运行 / 停止 ┐
├──────────┬──────────────────────────────────┬─────────────────┤
│ 文件轨    │ 001  代码编辑纸                  │ RESULT WINDOW   │
│ index     │ 002  带行号 textarea             │ 预览 / Console  │
│ styles    │ 003                              │ 时间 / 状态     │
│ script    │                                  │                 │
├──────────┴──────────────────────────────────┴─────────────────┤
│ 模板 / 重置             Ctrl+Enter 运行 · 本机自动保存          │
└───────────────────────────────────────────────────────────────┘
```

冷色纸面、搪瓷边框和实验标签来自教学机语义，不采用常见的纯黑背景加荧光单色。装饰被限制在编译纸带、穿孔边和状态章；其他区域用清晰边界与排版建立秩序。动画只用于纸带阶段切换和一次性的结果章落下，并尊重 `prefers-reduced-motion`。

## 架构、数据流与安全边界

`ide-core.js` 是零依赖 UMD 核心，负责模板克隆、模式与文件校验、代码统计、行号、控制台参数序列化、运行记录清洗和持久化数据迁移。`app.js` 只负责 DOM、快捷键、localStorage、Worker 生命周期和 iframe 预览。每种模式独立保存文件，运行历史只保留最近 20 条且不保存完整代码。

Web 预览把三个文件组装为 `srcdoc`，使用 `sandbox="allow-scripts"` 且不授予同源权限；注入的 CSP 禁止连接、外部脚本、表单和顶层导航，只允许内联样式/脚本与 `data:`、`blob:`、HTTPS 图片或媒体。预览通过随机运行标识向父页发送清洗后的 console 与运行错误。JavaScript Worker 重建最小 console，将可序列化输出回传；页面脚本无法接触主页面 DOM。Python Worker 使用 Pyodide 的 `setStdout`、`setStderr` 与 `runPythonAsync`，只回传纯文本。停止或超时会终止 Worker，下一次运行重新初始化。

## 错误处理与可访问性

空代码不会运行；未知文件和损坏缓存回退到官方模板。重复点击运行会先终止上一次任务。Python 下载失败、Worker 异常、JavaScript 语法/运行错误和 Web 预览错误都有稳定状态与下一步提示。所有用户代码只放入 textarea、Worker 消息或 sandboxed `srcdoc`，绝不写入主页面 `innerHTML`。

模式、文件、运行和重置均可键盘操作；`Ctrl/⌘ + Enter` 运行，`Escape` 停止。焦点环清晰，状态通过 `aria-live` 播报，输出窗口使用可聚焦日志区。390px 下没有横向页面溢出，编辑器内部可横向滚动；触控目标至少 44px。

## 验收范围

- Web 模板可编辑三个文件并在受限 iframe 中预览，console 与错误进入输出窗。
- JavaScript 在独立 Worker 中执行，支持标准输出、错误、停止和 8 秒超时。
- Python 在 Pyodide 模块 Worker 中按需加载并运行，显示加载阶段、stdout/stderr、结果与错误；网络失败可恢复。
- 三种模式、当前文件、代码草稿和最近运行摘要在本机持久化，重置只影响当前模式。
- Node 核心测试、语法检查、桌面与手机浏览器验收全部通过。
