# #029 英语单词卡片 (Word Cards)

翻卡记忆 + 艾宾浩斯间隔重复：CET4 高频 60 词。

## 功能
- **3D 翻卡**：CSS `transform-style:preserve-3d` + `backface-visibility` 真立体翻转
- **正面**：单词 + 卡片序号 + 熟练度标签
- **背面**：中文释义 + 例句
- **三操作**：😵 没记住 / 跳过 / 😀 记住了
- **四格统计**：待复习 / 已掌握 / 需巩固 / 当前熟练度
- **进度持久化**：队列状态和统计存 localStorage，关页续学
- **轮次机制**：一轮完成自动按熟练度重排，可再来一轮或重置

## 核心知识点：艾宾浩斯间隔重复（SM-2 简化版）
```
每词熟练度 lv 0-5：

记住了 → lv+1，卡片插回队列 2^lv 张之后
  lv1→2张后  lv2→4张后  lv3→8张后
  ——越熟越晚再见，符合遗忘曲线

没记住 → lv 归 0，仅插回 2 张后
  ——立刻短间隔重见，强化记忆

lv≥4 = 掌握 → 移出队列
会话内插队即模拟间隔重复；
跨天进度 localStorage 延续

例：abandon lv0 记住 → 2张后重见
    再记住 lv1 → 4张后 → 再记住 lv2 → 8张后
    连对3次后 lv3→4 掌握出队
```

## 技术栈
纯 HTML/CSS/JS 单文件，零依赖。
