# #034 TRACK/34 多任务倒计时

一个支持多条任务同时倒数的本地计时控制台。每条计时器可以独立开始、暂停、复位、增加一分钟或删除，也可以通过总控批量操作。打开 `index.html` 即可使用，无账号、无后端、无外部依赖。

## 功能

- **并行倒计时**：多个计时器独立运行，互不阻塞
- **单项控制**：开始、暂停、再次运行、复位、增加一分钟和二次确认删除
- **批量控制**：继续全部、暂停全部、全部复位
- **自定义时长**：支持小时、分钟、秒及 5/10/25/45 分钟快捷预设
- **到点提醒**：完成横幅、状态变化、ARIA 播报与可关闭的三音提示
- **精准恢复**：运行中保存绝对截止时间，刷新或切后台后按真实时间恢复
- **本地持久化**：任务和提示音偏好保存在 localStorage
- **快捷键**：`N` 新建计时，`Escape` 关闭窗口
- **响应式与可访问性**：桌面双列、移动端单列、可见键盘焦点、减少动态效果支持

## 核心知识点：保存截止时间

```text
开始计时
  ↓
endAt = Date.now() + remainingMs
  ↓
界面显示 endAt - Date.now()
  ↓
刷新 / 切后台 / 系统调度延迟
  ↓
仍按真实时间计算，不依赖 setInterval 累减
```

暂停时才把当前差值写回 `remainingMs`。因此定时器刷新后不会重新从旧秒数开始，也不会因为标签页降频而明显漂移。

## 数据结构

```javascript
{
  id, title, totalMs, remainingMs,
  endAt, status, theme, createdAt
}
```

状态包含 `running`、`paused` 和 `done`。页面只在状态变化时写 localStorage，每秒仅更新显示，减少不必要的存储写入。

## 视觉设计

界面取材自现场赛事计时台：冰蓝网格工作台承载多条任务赛道，深紫数字负责精确读时，朱橙用于撞线警报。每张卡片的分段赛道会随剩余比例缩短，让多个计时任务的紧迫程度一眼可比。

## 技术栈

纯 HTML / CSS / JavaScript 单文件，无框架、无构建步骤、无网络请求。
