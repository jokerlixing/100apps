# App 093 · 团队协作白板设计

## 产品定义

93 号项目定名为 **ROOM/93 · 团队协作白板**。它面向需要快速对齐想法的小团队，页面的单一任务是：进入一个共享房间，立即把便签、文本、形状和连接线组织成一张可讨论、可保存、可导出的白板。

公开版本必须能在 GitHub Pages 独立运行，因此协作采用本地优先模型：白板持久化在 localStorage，同源页面通过 BroadcastChannel 跨标签页同步操作和成员状态。它不是公网协作服务，也不会假装把数据上传到了服务器；界面会明确说明该边界。

## 方案取舍

1. **本地优先跨标签协作（采用）**：零后端、可部署、可以真实演示同步、离线仍可用。
2. WebSocket 服务端：能跨设备协作，但超出 GitHub Pages 的部署边界，增加账号、鉴权和数据保留成本。
3. 单页静态白板：实现最轻，但不满足“多人协作”的核心体验。

## 核心体验与数据流

- 首次进入加载“产品启动会”示例白板；用户也可以从空白、冲刺复盘、项目启动、用户旅程模板开始。
- 工具栏创建便签、文本、矩形、圆形和连接线。对象可选择、拖动、编辑、复制、删除、调整颜色和层级。
- 历史记录保留撤销/重做快照；每次本地变更先更新状态，再持久化并广播。远端标签页消息只更新状态，不回广播，避免回环。
- 房间码决定存储键和广播频道。在线成员通过定时 presence 消息与超时清理维护，光标通过节流消息展示。
- 导出支持结构化 JSON 和可独立查看的 PNG；导入 JSON 前验证版本与对象结构，失败时给出具体修复提示。

## 视觉方向

视觉主题是“项目作战室”，不是通用 SaaS 仪表盘。画布像贴在深蓝工作台上的制图纸，便签保留纸张厚度与手写标题，协作者光标像真实审阅标记。

- **Ink navy** `#172238`：顶栏与主文字。
- **Blueprint** `#2E5BFF`：选择、焦点与主要动作。
- **Paper** `#F5F7FB`：画布与面板。
- **Signal red** `#EF5B5B`：现场审阅标记。
- **Memo yellow** `#FFD86B`：默认便签。
- **Graphite** `#65708A`：辅助文字与网格。

字体角色使用 `Arial Narrow`/`Aptos Display` 作为紧凑标题，`Segoe UI` 负责正文，`Consolas` 负责房间码和缩放数据。签名元素是贯穿画布的蓝图坐标网格与实时协作者“审阅笔尖”。桌面为左侧模板架、中央画布、右侧检查器；窄屏收拢为可横向滚动工具带与底部检查器。

## 可靠性、边界与测试

- 核心状态函数保持为独立 UMD 模块，使用 Node 内置测试覆盖模板生成、对象增删改、撤销重做、导入校验和 PNG 绘制所需的边界计算。
- 浏览器冒烟覆盖首访、模板切换、创建/拖动/编辑、撤销重做、跨标签同步、刷新持久化、JSON 导出与桌面/移动截图。
- 所有按钮有可读标签与可见焦点；Delete、Ctrl/Cmd+Z、Ctrl/Cmd+Shift+Z、Ctrl/Cmd+D 提供高频键盘操作；减少动态效果偏好下关闭过渡。
- 协作仅限同一浏览器同源标签页；清除站点数据会移除白板；PNG 导出是当前白板快照。这些限制在 README 和房间面板中明确呈现。
