# App 047 · SHIFT/47 全图交换拼图设计

## 产品目标

做一个无需账号或网络服务的全图交换拼图。玩家从内置彩色创意桌面插画或自己的本地图片开始，将画面切成完整网格，通过拖拽或选择任意两块交换位置，最终恢复原图，并用更少交换次数和更短时间刷新本机纪录。

## 范围取舍

- 棋盘铺满 `N²` 个方块，不设置空格，不限制相邻位置。
- 使用 DOM 网格与 CSS 背景切片，兼顾拖拽反馈、响应式布局、键盘操作和自动化测试。
- 任意排列都可通过交换复原，因此直接使用 Fisher–Yates 打乱。
- 本地图片只在当前浏览器中读取，不上传服务器；记录只保存难度、用时和交换次数。
- 提供 3×3、4×4、5×5 三档，不加入提示求解器、排行榜或账号系统。

## 核心体验

1. 玩家选择内置图或本地图片，并选择难度。
2. 系统随机排列完整棋盘，所有格子都有图片内容。
3. 拖动一块到另一块上交换；也可依次点击两块，或用键盘选择。
4. 第一笔有效交换开始计时，界面持续显示用时、交换次数和当前难度。
5. 按住「查看原图」临时覆盖完整图片，松开后立即返回拼图。
6. 拼图完成后展示成绩、是否刷新纪录，并可直接再来一局。

## 视觉方向

主题为「SHIFT/47 图像修复台」，来自复古便携游戏机与液晶维修终端。机壳蓝、液晶灰、墨黑、按键黄和警示红继续构成控制台；内置图换成高饱和彩色俯视桌面，橙色相机、绿色植物、黄色耳机、红色咖啡杯、紫色笔记本、白色键盘、调色盘和彩铅让各区域都易于辨认。

拖拽时源方块像被从机台中拔出，目标方块出现黄色机械卡槽；点击选择使用同一视觉语言。减少动态效果开启时禁用缩放和旋转，仅保留清晰轮廓。

## 状态与数据流

- `puzzle-core.js` 维护完整棋盘创建、任意两块交换、Fisher–Yates 打乱、胜利判断和纪录比较。
- `app.js` 维护棋盘、尺寸、图片、计时、选择、拖拽、焦点和完成状态。
- 图片通过 FileReader 与 Canvas 转为正方形 data URL；失败时保留当前图片并显示页面内提示。
- 最佳纪录按图片类型、交换玩法和难度写入 localStorage，损坏时安全回退为空记录。

## 可访问性与边界

- 每块都是带目标位置说明的按钮；方向键移动焦点，Enter/空格选择，Esc 取消。
- Pointer Events 统一支持鼠标、触屏和触控笔拖拽，避免不同输入设备走两套交换逻辑。
- 拖回源方块、棋盘外释放或同一块重复选择均不计步。
- 难度切换、换图和重新打乱通过页面内确认条防止误操作。
- 上传文件必须是图片且不超过 8 MB；所有反馈均在页面内呈现。

## 可验证标准

- 单元测试覆盖完整棋盘、不可变交换、无效索引、无重复打乱、胜利判定和最佳纪录。
- 三档难度分别显示 9、16、25 个图片方块，且没有空格元素。
- 浏览器验证拖拽、触屏 Pointer、点击两块、键盘焦点、完成弹层和纪录恢复。
- 在 1440×900 与 390×844 视口无横向滚动或遮挡，控制台无错误。
- 根追踪器保持 47/100 完成，并链接到 GitHub Pages 项目地址。
