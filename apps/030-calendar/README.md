# #030 日历应用 (Calendar)

月视图日历：添加事件 + 今日高亮 + 五色标记。

## 功能
- **月视图 42 格**：6 周 × 7 列，前补上月尾/后补下月头（非本月半透明）
- **导航**：‹ › 翻月 + 今天按钮一键回当月
- **今日高亮**：金色边框 + 光晕
- **点选日期**：蓝色边框选中，下方事件面板显示该日事件
- **事件 CRUD**：文字 + 五色（蓝绿金红紫）标记，同名拦截，内联二次确认删除
- **事件预览**：桌面端格子内直接显示事件文字条（超 2 条折叠 +N）
- **移动端适配**：格子变小、事件文字条改色点
- localStorage 持久化

## 核心知识点：月历网格生成
```
JS Date 陷阱：getDay() 周日=0（不是周一=0）
  周一制转换：mondayIndex = (getDay()+6) % 7

42 格算法：
  firstDow = 本月1号是周几（周一制）
  start = 本月1号 - firstDow 天
  → 循环 42 格连续日期，自然覆盖前后月

事件数据结构：
  events = { "2026-08-28":[{text,color},...] }
  渲染时按格子日期键取——O(1) 命中
```

## 技术栈
纯 HTML/CSS/JS 单文件，零依赖。防抖规范全达标（hover 包裹/无垂直居中）。
