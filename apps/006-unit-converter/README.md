# 📐 #006 单位换算器 · Unit Converter

> 7 大类 60+ 单位互相换算：长度/重量/温度/面积/体积/速度/数据量，含常用速查表，点击结果一键复制。

## ✨ 功能

- 7 个类别标签切换，类别内任意两单位互转
- 换算按钮一键交换方向（结果值自动回填为输入）
- 科学计数法处理极大/极小值（避免 0.00000001 显示成 0）
- 每类常用速查表（1英里=?千米、1磅=?千克、体温98.6°F=?°C…），点击直接填充
- 结果点击复制

## 🛠 技术栈

纯 HTML / CSS / JS 单文件，零依赖。

**设计模式——基准单位归一化**：
- 每类选定基准单位（长度→米、重量→千克…），每个单位只需定义与基准的系数
- 任意换算 = `值 × from系数 / to系数`，新增单位只需加一行数据，不用写 N×N 换算表
- 温度是仿射变换（°F/°K 有截距偏移），用 `toBase/fromBase` 函数对象单独处理——数据驱动思想的进阶：**系数不够用时，把"怎么换算"本身也做成数据**

直接打开 `index.html`，或访问 GitHub Pages。无需联网。
