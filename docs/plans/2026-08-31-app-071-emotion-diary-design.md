# App 071 情绪日记设计

## 产品边界与核心闭环

71 号应用命名为 **TIDE/71**，服务于想用两三分钟记录当下、又不愿把私人日记交给云端账户的成年人。页面只承担一条主路径：记录一次情绪潮汐，回看一段时间内的变化，再得到可核对的数据观察和下一次书写提示。默认模式完全在浏览器本地运行，不要求账号、网络或 API Key；服务器配置 AI 提供商后，用户可以明确选择时间范围和是否包含日记摘录，再请求一次非诊断性的 AI 洞察。

每条记录包含心情强度、精力、最多五个情绪词、影响因素和一段可选文字。保存后立即出现在潮汐图与记录簿中；用户可以编辑、删除、按 7 天、14 天或 30 天查看趋势，并导出本地备份。趋势区只陈述可以从数据复算的事实，例如平均心情、记录频率、波动、常见因素和满足最小样本数的因素差异，不把相关性写成原因。AI 输出限定为观察、温和的反思问题和可执行的小步骤，并持续显示“不是诊断或治疗建议”。

核心闭环是“停一下 → 记录 → 看见变化 → 带着一个问题继续生活”。第一版不加入社交分享、云同步、连续打卡惩罚、情绪人脸识别、疾病判断、危机自动判定或治疗建议。应用不是医疗产品；当用户需要紧急帮助时，界面只建议联系当地紧急服务、可信任的人或专业机构，不声称能识别风险等级。

## 架构、数据流与隐私

`emotion-core.js` 是零依赖 UMD 模块，负责输入归一化、记录排序与去重、时间范围筛选、趋势统计、因素模式、本地洞察、导入数据校验、AI 请求摘要和不可信 AI 响应清洗。所有统计都返回样本量；因素模式至少需要三条相关记录才显示。文字长度、情绪词、因素数量、历史条数和日期范围都有明确上限，导入数据逐条清洗，不接受原型字段或 HTML。

浏览器控制器维护填写、趋势、记录簿、编辑与隐私设置。记录保存在 `tide71.entries.v1`，最多 365 条；AI 开关和“包含文字摘录”选择不持久化。请求 AI 前先在本地展示将发送的记录数、字段范围和是否含摘录，用户再次确认后才向同源 `/api/insights` 发送。默认负载只含日期、心情、精力、情绪词和影响因素；文字摘录默认关闭并限制长度。无论 AI 是否成功，本地趋势和记录都保持可用。

`server.js` 仅使用 Node 内置 HTTP、Fetch 与文件 API。密钥只从 `AI_API_KEY` 读取，模型和兼容端点由 `AI_MODEL`、`AI_BASE_URL` 配置。接口限制 JSON 请求体、记录数、文本总量和上游时间，使用核心模块再次清洗输入输出；未配置、超时和异常响应返回稳定错误，不泄露密钥、提示词或上游正文。测试覆盖统计边界、日期过滤、因素样本阈值、导入清洗、摘录选择、恶意 AI 数据、静态文件白名单和路径穿越。

## 视觉系统与响应式布局

视觉取材于海洋观测员的潮汐记录簿，而不是常见的柔和渐变“心理健康”卡片。色板为雾岸灰 `#E4E9E7`、深水墨 `#1C2B33`、潮位蓝 `#3C7C91`、海藻绿 `#416A5C`、落日橙 `#EE9A62`、暮色紫 `#735E76`。标题使用紧凑的 `Bahnschrift SemiCondensed` / `Microsoft YaHei`，正文使用 `Segoe UI`，日期和刻度使用 `Cascadia Mono`；日记摘录用 `KaiTi` 作为克制的叙事层，不把整页做成手写风。

桌面端左侧是今天的观测卡，右侧是 14 天潮位纸；下方记录簿按日期展开。标志性元素是一条“情绪潮位线”：纵向位置来自心情，节点直径来自精力，颜色来自主情绪词，点击节点会定位到对应记录。它承载真实数据，不是装饰。唯一主动画发生在保存时：新节点沿刻度升到实际潮位；其余状态变化采用短淡入，并在 `prefers-reduced-motion` 下全部取消。

界面自检后删去了容易模板化的柔和渐变大标题、悬浮玻璃卡片和虚构健康分数，改用观测表格、真实日期刻度与纸带装订结构。桌面布局是“观测卡 + 潮位纸”，移动端按“记录 → 结论 → 图表 → 记录簿”单列排列；触控区不小于 44px，图表提供文字摘要和可聚焦节点，所有状态由 `aria-live` 播报，390px 宽度不得出现横向滚动。
