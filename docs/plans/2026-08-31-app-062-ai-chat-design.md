# App 062 AI 聊天助手设计

## 产品边界

62 号应用命名为 **WIRE/62**，面向想快速连接自有兼容 OpenAI 接口、又不想安装客户端的个人用户。它是一座浏览器里的“对话通讯台”：用户填写接口基址、模型和临时密钥后即可流式对话、停止生成、重试上一轮、复制回复，并在本机保留多个会话。应用使用广泛兼容的 `POST /chat/completions` 消息格式；不内置服务商、不代管账号、不承诺任意接口都允许跨域访问。

这是一个静态 BYOK 作品集项目，不是生产密钥托管方案。OpenAI 官方明确要求不要在浏览器客户端暴露 API 密钥，因此 WIRE/62 不会把密钥写入源码、URL、localStorage、IndexedDB 或导出文件；密钥只存在当前页面的 JavaScript 内存中，刷新即清除。连接面板会持续显示风险提示，建议仅使用低额度、可撤销的个人测试密钥。正式团队或公开产品应改用服务端代理。

## 架构与数据流

`chat-core.js` 是零依赖 UMD 核心：验证 HTTPS/localhost 接口、构造 `/chat/completions` 地址、清洗会话、生成标题、裁剪上下文、构造请求体、解析跨分块 SSE，并从增量块提取文本。`app.js` 负责 DOM、localStorage、Fetch、AbortController 和流式渲染。持久化数据只有接口基址、模型、系统提示、温度与对话记录；密钥由独立内存变量持有。

发送时先保存用户消息，再插入空的 assistant 占位。Fetch 使用 Bearer 认证与 `stream: true`；读取器把字节交给增量 SSE 解析器，每个有效 `data:` 事件只追加当前 choice 的文本。停止生成会中止请求并保留已生成片段，标记为“已停止”；网络、鉴权、限流、CORS、空响应和畸形事件都有可执行的中文提示。重试会删除最后一条 assistant 回复并重新发送同一上下文，避免重复用户消息。

## 界面与视觉

视觉来自真实通讯室的跳线台，而不是常见的紫色渐变聊天卡片。色板为报文纸 `#e7edf0`、深海墨 `#172538`、线路红 `#e44935`、信号青 `#0b8b8f`、接点黄铜 `#d7a84a` 与洁净白 `#f8fbfc`。标题使用 `Arial Narrow` / `Aptos Narrow`，正文使用 `Segoe UI`，状态、时间和模型参数使用 `Consolas`。

桌面端左侧是会话电报码，中间是连续消息纸带，右侧是连接跳线台；移动端只保留纸带，把两侧变成抽屉。签名元素是一根贯穿消息的“信号线”：用户与助手消息像接在线路上的报文节点，生成时线路沿阅读方向脉冲，停止后变为明确的断点。界面只在信号线和流式光标上使用动效，并完整支持 `prefers-reduced-motion`。所有操作有可见焦点，触控目标至少 44px，状态变化通过 live region 宣告。

```text
┌ 会话电报码 ┐┌──────── 报文纸带 / 对话 ────────┐┌ 连接跳线台 ┐
│ 新建       ││ WIRE/62  当前模型   线路状态     ││ 接口       │
│ 08/31 计划 ││     ● 用户报文                   ││ 模型       │
│ 08/30 文案 ││     │ 助手流式回复                ││ 临时密钥   │
│            ││     ● 下一轮                     ││ 参数/提示  │
└────────────┘└──────── 输入与发送/停止 ────────┘└────────────┘
```

## 验证标准

核心测试覆盖接口规范化、危险 URL 拦截、会话清洗、标题生成、上下文裁剪、请求体、SSE 任意分块、`[DONE]`、错误事件与增量文本提取。浏览器冒烟测试使用本机 mock SSE 服务，不需要真实密钥，验证配置、逐块显示、停止、重试、复制、新建/切换/删除会话、刷新持久化、密钥不落盘、桌面 1440px 与手机 390px、无横向溢出、键盘焦点以及无未处理错误。
