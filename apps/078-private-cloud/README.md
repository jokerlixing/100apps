# DEPOT/78 · 私人网盘

DEPOT/78 是一个静态、零依赖的浏览器本地资料库，完成 100 Apps Challenge 的第 78 个项目。它支持真实文件上传与下载、资料夹、文本/图片/音视频预览、本地分享口令、回收站和逻辑配额台账。

## 运行方式

直接访问公开版本：

`https://jokerlixing.github.io/100apps/apps/078-private-cloud/`

本地建议通过任意静态服务器打开目录，例如在仓库根目录运行：

```powershell
python -m http.server 4178
```

再打开 `http://127.0.0.1:4178/apps/078-private-cloud/`。直接使用 `file://` 可能受到浏览器 IndexedDB 或模块策略限制。

## 数据与隐私边界

- 文件 Blob、文件元数据、资料夹和分享口令都保存在当前浏览器的 IndexedDB 中，不会由应用上传到第三方。
- 512 MiB 是应用自己的逻辑配额，不代表浏览器或磁盘的真实可用容量；浏览器仍可能因设备空间、站点策略或私密模式限制而拒绝写入。
- 回收站中的文件仍占用配额，永久删除后才释放。
- 分享链接只携带随机口令，不携带文件名或内容。它只能在已经保存同一份资料的当前浏览器中解析，不是跨设备或公网文件分享。
- 这是个人资料库演示，不提供账号、跨设备同步、服务端备份、访问审计或加密密钥管理。不要把它当成重要资料的唯一副本。

## 功能说明

- 拖放或批量选择文件；同目录重名会自动追加序号。
- 按全部、最近、共享、回收站、资料夹和文件类型筛选，并按时间、名称或大小排序。
- 可删除空或非空资料夹；夹内文件会安全迁回总库，回收站状态保持不变。
- 图片、音频、视频和常见文本可在借阅卡中预览；其他格式保留下载入口。
- 分享口令支持 1、7、30 天或长期有效，可重新生成或撤销。
- 删除先进入回收站，可恢复；永久删除需要二次确认。
- 首访提供三份小型文本示例，帮助理解操作，不会在后续访问中重复覆盖。

## 键盘与无障碍

- `Tab` 可遍历筛选、文件行与操作按钮，焦点环始终可见。
- 入库轨道获得焦点后可按 `Enter` 或空格打开文件选择器。
- 主要状态变化通过 `aria-live` 播报。
- 窄屏上的文件详情使用原生 dialog 语义；主要触控目标不小于 44px。
- `prefers-reduced-motion` 下关闭文件入轨与容量尺过渡动画。
