# App 088 · 可视化大屏编辑器设计

## 产品定位

`GRID/88` 是给小团队运营、活动与数据负责人使用的本地大屏编辑器。它的单一任务是：把 JSON 或 CSV 数据绑定到可拖拽组件，快速排成一张可保存、可预览、可迁移的大屏。应用完全在浏览器中运行，不上传数据，也不依赖第三方接口。

## 方案取舍

比较过三条路线：接入重型图表与拖拽库、使用 Canvas 自绘编辑器、使用原生 DOM + SVG。重型库能力最全，但会引入网络与构建依赖；Canvas 性能高，但表单编辑、可访问性和响应式处理复杂。最终采用原生 DOM + SVG：12 列网格负责布局，SVG 负责柱状图、折线图和环图，表格与指标卡使用语义化 HTML。它满足离线、易部署和可测试三个核心约束。

## 信息架构与交互

```text
┌ 组件仓 ┐  ┌──────── 带标尺的信号网格画布 ────────┐  ┌ 数据与属性 ┐
│ 指标卡  │  │ 标题 / 状态                         │  │ 数据源      │
│ 柱状图  │  │  ┌───────┐  ┌────────────┐          │  │ 字段绑定    │
│ 折线图  │  │  │ 指标卡 │  │  折线图     │          │  │ 布局与样式  │
│ 环形图  │  │  └───────┘  └────────────┘          │  │ JSON / CSV  │
│ 数据表  │  │  ┌──────────────────────┐            │  │             │
└────────┘  │  │      可拖拽组件       │            │  └─────────────┘
            └──────────────────────────────────────┘
```

- 从组件仓点击或拖入组件；画布内组件可拖动，键盘方向键可微调。
- 选中组件后在右栏绑定数据源、标签字段和值字段，并编辑标题、强调色和网格尺寸。
- 数据源支持粘贴 JSON 数组或含表头的 CSV；解析失败时保留原数据并给出明确错误。
- 编辑态显示网格、标尺、组件边框和选中状态；预览态隐藏编辑控件并按大屏比例呈现。
- 工作区自动保存到 `localStorage`；支持重置示例、导出项目 JSON、导入项目 JSON。

## 视觉方向

- `Paper fog #E8EDF1`：外部工作台背景。
- `Ocean ink #102A38`：画布与主结构色。
- `Signal coral #FF6B4A`：主要动作与选中态。
- `Data cyan #53C7C9`：图表数据与连线。
- `Meter yellow #F0C85A`：辅助数据序列。
- `Chalk #F7FAFC`：大屏文字与面板。

标题使用 `Bahnschrift Condensed` 表达控制台铭牌感，正文使用 `Aptos/Segoe UI`，数据与标尺使用 `Cascadia Mono/Consolas`。独特元素是画布上真实参与布局的列标、行标与信号网格；装饰被限制在这一处，其余控件保持克制。

## 数据与错误边界

项目状态由数据源、组件、画布设置和当前选择组成。持久化前会规范化并限制网格边界；导入时验证版本与结构。图表遇到空值、负值或非数字值时按零处理；无可用记录时展示带操作建议的空状态。删除数据源时，已绑定组件自动回落到首个可用数据源。

## 验证策略

- 核心单元测试覆盖 CSV/JSON 解析、字段推断、系列解析、网格边界和项目导入导出。
- 静态检查验证应用入口、无远程依赖和关键可访问性属性。
- 浏览器冒烟测试覆盖添加组件、拖动、绑定数据、预览切换、持久化与桌面/移动布局。
- 最终运行全量项目测试和根追踪器测试，再同步 GitHub `origin`。
