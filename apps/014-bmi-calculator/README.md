# #014 BMI 计算器 (BMI Calculator)

滑杆输入的 BMI 计算器：实时计算 + 彩色标尺定位 + 健康建议 + 历史记录。

## 功能
- **双滑杆**输入身高体重（120-220cm / 30-150kg），拖动即时计算
- **双标准切换**：中国成人标准（18.5/24/28）vs WHO 国际标准（18.5/25/30）
- **彩色标尺**：蓝→绿→橙→红四段 + 白色指针实时定位你的 BMI 位置
- **理想体重区间**：反向用公式算出你身高对应的健康体重范围
- **分级健康建议**：偏瘦增肌 / 正常保持 / 超重减脂 / 肥胖就医四套文案
- **历史记录**：保存每次测量（日期+数值+分级），最多 20 条，二次确认清空

## 核心知识点
```
BMI = 体重(kg) ÷ 身高(m)²

理想体重区间 = [18.5, 23.9] × 身高²   ← 公式反推
标尺指针位置 = (BMI - 15) / 20 × 100%  ← 数值线性映射
```

## 细节
- 中国标准比 WHO 更严（24 即超重，WHO 是 25）
- BMI 不区分肌肉和脂肪（健身人群会"虚高"），页脚有免责说明
- 分级颜色联动：数字、分类、标签、指针统一变色

## 技术栈
纯 HTML/CSS/JS 单文件，无依赖。
