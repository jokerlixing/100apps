# App 047 · SHIFT/47 滑块拼图设计

## 产品目标

做一个无需账号或网络服务的经典滑块拼图。玩家从内置插画或自己的本地图片开始，将画面切成规则网格，通过唯一的空格逐步移动方块，最终恢复原图，并用更少步数和更短时间刷新本机纪录。

## 范围取舍

- 采用留一个空格的滑块规则，不做自由拖拽交换或不规则拼片。
- 使用 DOM 网格与 CSS 背景切片，兼顾移动动画、响应式布局、键盘操作和自动化测试。
- 只用合法移动从完成状态打乱，天然保证每一局可解，不依赖逆序数补救。
- 本地图片只在当前浏览器中读取，不上传服务器；记录只保存难度、用时和步数。
- 首版提供 3×3、4×4、5×5 三档，不加入提示求解器、排行榜或账号系统。

## 核心体验

1. 玩家选择内置图或本地图片，并选择难度。
2. 按下「开始打乱」后，系统从完成状态执行足量且避免立即回退的合法移动。
3. 点击空格相邻方块、按方向键或在拼图上滑动，方块移入空格；非相邻方块不会移动。
4. 第一记有效移动开始计时，界面持续显示用时、步数和当前难度。
5. 按住「查看原图」临时覆盖完整图片，松开后立即返回拼图。
6. 拼图完成后展示成绩、是否刷新纪录，并可直接再来一局。

## 视觉方向

主题名为「SHIFT/47 滑块修复台」，来自复古便携游戏机与液晶维修终端，而不是通用卡片仪表盘。

- `#2859D8` 机壳蓝：页面主结构与品牌色。
- `#D8E0D0` 液晶灰：游戏屏幕和主要内容底色。
- `#172018` 墨黑：文字、屏幕边框和空格检修口。
- `#F4C842` 按键黄：主要操作与当前选择。
- `#E34B42` 警示红：重置、完成印章与异常反馈。
- `#F3F0E8` 外壳白：背景留白与控制区。

大标题使用本地窄体工业字体栈，正文使用清晰的系统中文无衬线，计时和步数使用等宽字体。桌面端以大拼图屏幕配窄控制台，移动端折为上下布局。唯一的视觉冒险是「空格轨迹」：最近移动经过的位置出现短暂液晶残影，既强化主题也帮助玩家理解移动路径；减少动态效果开启时直接禁用。

## 状态与数据流

- `puzzle-core.js` 维护纯函数：创建完成棋盘、判断相邻、移动方块、合法打乱、胜利判定和纪录比较。
- `app.js` 维护界面状态：棋盘、尺寸、图片、开始时间、步数、运行状态、预览状态与最近轨迹。
- 图片通过 `FileReader` 转为临时 data URL，仅用于当前页面；失败或格式不支持时保留原图并显示页面内提示。
- 最佳纪录写入 `localStorage`，按图片类型与难度分组；存储损坏时安全回退为空记录。

## 可访问性与边界

- 拼图是带说明的网格；每块含可读编号与目标位置，空格有明确标签。
- 可点击方块使用按钮，键盘方向键与触屏滑动均可完成主流程，焦点样式清晰。
- 难度切换或换图会创建新局，进行中的局面通过页面内确认条防止误操作。
- 上传文件必须是图片且不超过 8 MB；错误信息说明原因和修复办法。
- 所有确认、错误与完成反馈都在页面内呈现，不使用 `alert` 或 `confirm`。

## 可验证标准

- 单元测试覆盖完成棋盘、相邻判断、非法/合法移动、可解打乱、胜利判定和最佳纪录比较。
- 打乱结果非完成态、方块不重复且只能由合法移动序列产生。
- 浏览器验证 3×3 完整通关、键盘与滑动输入、按住预览、本地图片错误，以及刷新后的纪录恢复。
- 在 1440×900 与 390×844 视口无横向滚动或遮挡；减少动态效果设置生效。
- 根追踪器显示 47/100，并链接到 GitHub Pages 项目地址。
