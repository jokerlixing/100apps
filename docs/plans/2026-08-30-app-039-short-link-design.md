# App #039 CUT/39 短链接服务设计说明

## 产品定位

面向需要整理活动链接、作品入口和临时资料地址的独立创作者。页面只有一个核心任务：把难以辨认的长网址整理成一枚好记、可管理、能在本机统计点击的短标签。

## 方案比较

1. **包裹路由工作台（采用）**：长网址像待分拣地址带，短别名像包裹标签，创建、跳转与点击记录都能使用真实的路由语言。
2. **深色开发者终端**：与 URL 技术感契合，但容易落入黑底荧光色的常见模板，普通用户也不够亲切。
3. **营销数据后台**：统计清晰，却会让最重要的“快速生成短链”退居次位。

## 视觉系统

## 标志性元素

“链路切片机”横跨首屏：长网址从左侧进入带刻度的轨道，经过橙色刀口后，在右侧变成青柠色短签。生成链接时只让短签执行一次弹出动作，其他区域保持安静。

## 数据与路由

每条链接包含 id、slug、目标 URL、标题、标签、创建时间和点击事件数组。短链使用当前页面地址加 Hash 路由 `#go=<slug>`；打开后页面先进入跳转门并记录一次本机点击，展示目标域名，再由用户主动继续访问。

Slug 只允许小写字母、数字和短横线，长度 3–24；留空时根据标题或域名生成并自动解决冲突。目标地址只允许 http 与 https，解析成功后移除首尾空格。搜索匹配标题、slug、域名、目标和标签。

## 静态托管边界

- 短链目录与点击事件保存在当前浏览器的 localStorage
- `#go=<slug>` 只有在已保存该 slug 的浏览器中才能解析
- 分享给另一台设备前，需要在该设备重建相同短签；本版本不伪装成云端短域名服务
- 跳转门不会自动发送或上传数据，继续访问始终由用户主动触发

## 统计口径

- 总点击：所有本地链接的点击事件数
- 今日点击：按本地日期统计当天事件
- 七日趋势：最近七个本地自然日的事件总数
- 点击排行：按点击次数降序，次数相同时按最近创建排序
- 打开短链 Hash 即记录一次，管理页的普通查看与复制不计数

## 验收标准

- 有效 URL 可创建短签，自定义别名能校验格式和重复
- 自动别名稳定、冲突时自动追加序号
- 短链可复制，打开 Hash 后出现跳转门并增加一次点击
- 搜索、标签筛选、复制、编辑和二次确认删除正常
- 七日趋势、总点击、今日点击和排行榜统计正确
- 损坏存储自动回退，所有用户文本经过 HTML 转义
- 桌面与 390px 手机布局无横向溢出，键盘焦点清楚并尊重减少动态效果
- 追踪器显示 39/100，第 039 项链接和完成态正确
