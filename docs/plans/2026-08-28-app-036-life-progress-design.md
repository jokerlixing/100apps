# App #036 人生进度条设计说明

## 产品定位

面向希望把抽象时间变成可行动信息的人。页面的单一任务是：让用户在同一个视野中看清人生、自然周期与个人目标已经走了多远，接下来还有多少时间或工作量。

## 方案比较

1. **时间测绘所（采用）**：以测绘刻度、游标和图纸批注表达进度。信息密度适中，既适合人生长周期，也适合日、周、月等短周期。
2. **宇宙航行舱**：用轨道和星体表达时间，情绪感染力强，但精确数值与表单可读性较弱。
3. **数据仪表盘**：卡片与普通进度条最直观，但视觉识别度低，难以承载“人生时间”这一主题。

## 视觉系统

- 雾蓝纸面 `#e8edf0`：页面底色，模拟测绘图纸
- 图纸白 `#f8faf8`：主要工作区
- 海军蓝 `#102b46`：文字、边框与结构线
- 朱红 `#ef5748`：当前时间游标和关键操作
- 柠檬黄 `#f1d85a`：注释、提示和目标标记
- 青绿 `#2b9b8d`：健康状态与完成反馈
- 标题：`Arial Black` / `Microsoft YaHei`，短促而像制图编号
- 正文：`Trebuchet MS` / `Microsoft YaHei`
- 数据：`Cascadia Mono` / `Consolas`

## 关键交互与数据流

用户设置出生日期和目标年龄后，应用以本地时间计算当前年龄、已经历天数和预计目标日期。自然周期根据当前年份、月份、周一至周日和当天的真实起止时间计算，今日进度每秒更新。人生进度与周期进度都使用同一套 `elapsed / total` 计算并限制在 0–100%。

个人目标包含名称、当前值、目标值、单位、颜色和可选截止日期。添加、编辑、调整进度与删除都会写入 `localStorage`；删除需要二次确认。首次打开提供示例目标，用户数据不离开设备。

## 边界与错误处理

- 出生日期不能晚于今天，目标年龄限制为 1–150 岁
- 目标总量必须大于 0，当前值不能小于 0，可超过目标值但显示按 100% 封顶
- 无效的本地存储自动回退到默认值
- 剪贴板能力不可用时使用文本框回退复制
- 预计寿命只是用户自定义的观察尺度，界面明确说明它不是预测

## 验证标准

- 在固定时间下核对人生、年、月、周、日的边界计算
- 检查设置保存、目标 CRUD、增减进度、二次确认删除和刷新恢复
- 检查桌面与移动端布局、键盘焦点、ARIA 播报及减少动态效果
- 确认首页第 036 项完成态、名称、说明和 GitHub Pages 链接一致
