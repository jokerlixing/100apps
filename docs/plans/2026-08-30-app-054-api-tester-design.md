# App 054 API 测试工具设计

## 产品边界

54 号应用命名为 **PORT/54**，面向需要快速验证公开 HTTP 接口的前端开发者和学习者。页面只完成一条主流程：编排一个请求、从浏览器发出、读懂响应并在本机复用历史记录。它不提供账户、云同步、团队空间、脚本执行或绕过浏览器安全策略的代理；跨域请求被目标服务拒绝时，界面会明确解释 CORS，而不是把它包装成普通网络错误。

## 请求与数据流

请求工作台支持 GET、POST、PUT、PATCH、DELETE 和 HEAD，URL 必须是 `http:` 或 `https:`。查询参数和请求头都使用可增删、可启停的键值行，并在发送前合并进最终 URL 和 Headers。POST/PUT/PATCH/DELETE 可编辑 JSON 或纯文本正文；JSON 会在发送前校验，并可一键格式化。请求使用 `fetch` 与 `AbortController`，提供 3–60 秒超时和手动取消。响应读取状态、耗时、大小、响应头与文本正文；JSON 自动格式化，其余内容安全地以纯文本显示，避免执行远程 HTML。成功或失败的最近 12 条请求保存在 localStorage，敏感头值不会写入历史。

## 信息架构

桌面端是左侧请求编排台与右侧响应检查台，顶部方法和 URL 形成一条连续的“发射轨”。请求区用 Query、Headers、Body 三个页签控制复杂度；响应区用 Body、Headers、Request 三个页签帮助复盘。左侧边缘放最近历史抽屉，窄屏时收进顶部按钮。空状态直接提供三个公开示例，其中内置 `data:` 演示可在离线环境验证界面；浏览器不允许通过 fetch 使用非 HTTP URL，因此真正发送仍严格限制在 HTTP(S)，单元测试只覆盖 URL 编排逻辑。

## 视觉方向

界面取材于网络分析仪和跳线标签，而不是常见的深色霓虹终端。颜色为冷瓷白 `#f4f7f6`、深海军蓝 `#13263b`、信号钴蓝 `#2257d5`、连接橙 `#ff6b35`、成功青绿 `#1a9b78`、网格灰 `#cfd8dc`。标题使用 `Arial Narrow`/Impact 的压缩字形，正文使用 `Segoe UI`，代码与数据使用 Consolas。签名元素是一根贯穿两栏的垂直“脉冲轨”：等待、发送、成功和失败分别改变轨道灯色，并在发送时只有一次受控脉冲。结构保持直角、细网格和小号设备标签；避免装饰性卡片堆叠，动效遵守 `prefers-reduced-motion`。

## 错误与隐私

输入错误会定位到具体字段；重复或空键被忽略。超时、手动取消、CORS/网络错误、HTTP 错误状态使用不同文案，HTTP 4xx/5xx 仍展示服务器响应。Authorization、Cookie、Proxy-Authorization、X-API-Key 等敏感头只存在当前表单内，保存历史时统一替换为遮罩，重新载入历史不会自动恢复秘密。清空历史需二次确认。

## 验证标准

核心测试覆盖 URL 协议校验、查询参数合并、请求头清洗、敏感字段遮罩、正文准备、响应内容识别、字节格式化和历史上限。浏览器验证覆盖示例请求、JSON 格式化、请求取消、成功/HTTP 错误/CORS 提示、响应页签、复制与下载、历史恢复、刷新持久化、键盘操作、1280px 桌面与 390px 手机布局、控制台错误和减少动态效果。
