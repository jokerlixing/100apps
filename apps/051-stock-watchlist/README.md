# TICK/51 · 股票自选行情

一款纯前端的本地自选行情纸带。它可以免密刷新 A 股、港股和美股报价，查看 1 月、3 月、6 月和 1 年复权日 K，并在网络不可用时明确切换到可交互的样例数据。

## 功能

- 最多保存 8 个自选标的，刷新后仍会恢复
- 每 60 秒自动刷新，也支持手动刷新
- 显示现价、涨跌、今开、最高、最低、昨收和成交量
- Canvas 绘制 K 线与成交量，鼠标、触摸和方向键均可逐根读取
- A 股采用 `600519` / `000001.SZ`，港股采用 `00700.HK`，美股采用 `AAPL`
- 接口失败时保留上一次成功数据；首次失败时使用带标识的样例数据
- `?demo=1` 可强制进入不请求网络的样例模式
- 桌面、平板和手机响应式布局，支持减少动态效果和键盘焦点

## 数据说明

报价和 K 线来自腾讯行情公开接口，不需要 API Key。不同市场的数据新鲜度和历史深度可能不同；例如接口没有返回足够的美股历史 K 线时，页面会保留真实报价，并把图表明确标为“K 线样例”。行情仅用于 Web 技术学习，不构成投资建议。

应用不会上传自选列表。列表和当前选中项只保存在当前浏览器的 `localStorage` 中。

## 本地运行

从仓库根目录启动任意静态服务器，例如：

```bash
python -m http.server 8000
```

然后访问：

```text
http://127.0.0.1:8000/apps/051-stock-watchlist/
```

离线样例模式：

```text
http://127.0.0.1:8000/apps/051-stock-watchlist/?demo=1
```

## 测试

```bash
node --test apps/051-stock-watchlist/market-core.test.js
node --check apps/051-stock-watchlist/app.js
```

核心测试覆盖证券代码规范化、腾讯行情文本解析、K 线解析、区间映射、图表边界、涨跌幅和指针索引。

## 文件

- `index.html`：语义结构和无障碍标签
- `styles.css`：TICK/51 打孔行情纸带视觉与响应式布局
- `market-core.js`：可独立测试的行情领域逻辑
- `app.js`：网络请求、自选状态、自动刷新和 Canvas 绘制
