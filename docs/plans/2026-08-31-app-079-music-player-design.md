# REEL/79 音乐播放器设计

## 产品边界

79 号项目是一台本地优先的浏览器音乐播放器，面向希望整理自己的音频、又不愿注册账号或上传文件的用户。页面的单一任务是：让用户把本地音频组织进歌单，并在一个可信、可恢复的播放台里完成播放与同步歌词阅读。GitHub Pages 版本不依赖音乐服务、登录、密钥或第三方曲库；内置三段原创浏览器合成示例曲目，确保首次打开即可完整体验。

实现采用静态 HTML、CSS 与原生 JavaScript。可复用的 `player-core.js` 负责时间格式、LRC 解析、歌词定位、歌单归一化、队列排序、下一首决策和播放模式；`app.js` 负责 DOM、AudioContext、`<audio>`、IndexedDB、本地偏好与浏览器媒体会话。内置示例曲目用 Web Audio API 现场合成，用户音频只在当前浏览器 IndexedDB 中保存，不上传网络。若浏览器拒绝持久化或空间不足，界面明确说明文件仅在本次会话可用。

## 核心流程

首次进入默认打开“样带 / SAMPLE REEL”，里面有三首原创合成曲目及时间码歌词。用户可以播放、暂停、切歌、拖动进度、调节或静音音量，切换顺序、随机、单曲循环和列表循环。歌词会随当前时间滚动，点击歌词可跳转；没有歌词时显示导入 LRC 的具体操作。

“导入音频”接受常见浏览器音频格式，读取名称、时长和 MIME 类型，单次最多 20 个、每个最多 80 MiB，并写入 IndexedDB。用户可以创建、重命名、删除歌单，把曲目加入或移出当前歌单，并用键盘按钮上移或下移。选中本地曲目后可导入 LRC；解析后歌词与曲目 ID 一起持久化。删除曲目会先确认，并从所有歌单及 IndexedDB 中移除。

刷新后恢复歌单、顺序、收藏、音量和播放模式，但不会自动播放。当前曲目存在时恢复选择和上次进度；只有用户再次点击播放才恢复声音。所有破坏性动作都用原生对话框确认，错误信息说明发生了什么以及下一步怎么做。

## 视觉系统

视觉来自 1980 年代便携式磁带录音机和广播站节目单，而不是常见的黑底霓虹播放器。调色板为机壳蓝灰 `#26343d`、磁带奶油 `#eee5cf`、氧化铁红 `#b84632`、电平表黄 `#e5b94a`、标记蓝 `#4e7f94`、铅字黑 `#171c1f`。标题使用 `Arial Narrow` / `Bahnschrift SemiCondensed`，正文使用 `Segoe UI` / `Microsoft YaHei`，时间码和设备标签使用 `Cascadia Mono` / `Consolas`。

桌面版是三栏工作台：左侧歌单档案盒，中间磁带机与运输控制，右侧连续节目单歌词。磁带窗是唯一的强视觉元素：两个卷盘的填充比例随播放进度变化，播放时转动，暂停后静止，减少动态效果时完全禁用旋转。歌曲编号、时长、队列位置和歌词时间码都表达真实数据，不做装饰编号。

```text
┌───────────────┬──────────────────────────────┬──────────────────┐
│ 歌单档案盒     │ REEL/79 磁带运输台            │ 节目单 / 歌词      │
│ + 新建         │ ┌────卷盘──────卷盘────┐      │ 00:00 前奏        │
│ 样带       3   │ │     当前曲目与磁带进度 │      │ 00:14 当前行       │
│ 夜间列车   4   │ └─────────────────────┘      │ 00:28 下一行       │
│               │  ◀  ▶/Ⅱ  ▶│  随机  循环      │                  │
│ 曲库 / 导入    │ 队列：曲目、时长、移动、移除    │ 导入 LRC           │
└───────────────┴──────────────────────────────┴──────────────────┘
```

在 980px 以下，歌词移到磁带台下方；在 680px 以下，歌单、播放台、队列和歌词依次纵向排列。所有操作至少 44px，键盘焦点使用电平表黄和深色双线，不依赖悬停；状态文字、`aria-live` 与原生控件确保颜色之外仍能理解。歌词区有 `aria-label`，当前歌词使用 `aria-current`，卷盘只是装饰并对辅助技术隐藏。

## 数据、安全与失败处理

状态分为两层：小型元数据写入 `localStorage`，用户音频 Blob 写入 `reel79.library.v1` IndexedDB。文件名、歌词和歌单名在渲染前只通过 `textContent` 进入页面；不解析音频标签中的 HTML，不执行歌词内容。对象 URL 在切歌和离开页面时撤销。导入限制数量、大小和 MIME/扩展名，数据库错误会保留内存副本并提示持久化失败。

内置合成曲目不声称来自真实艺人，曲名、作者和歌词均为项目原创。浏览器不支持 AudioContext 时，仍允许导入并播放本地音频；不支持 IndexedDB 时，当前会话继续工作。媒体快捷键只在功能存在时注册。页面不发出任何远程请求，README 明确隐私边界和浏览器存储清除后数据会丢失。

## 验证

Node 核心测试覆盖 LRC 多时间码、偏移、无效行、歌词二分定位、名称与歌单边界、重复曲目、队列移动、播放模式和时间格式。浏览器冒烟覆盖首次示例播放、进度与歌词同步、拖动、音量、随机/循环、创建和重命名歌单、导入音频与 LRC、移动/删除、刷新恢复、键盘焦点、桌面与 390px 布局、无横向滚动和无运行时错误。最终截图只展示验证后的真实页面。
