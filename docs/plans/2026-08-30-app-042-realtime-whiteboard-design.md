# App #042 BOARD/42 多人实时白板设计说明

## 产品定位

面向远程小组、结对开发者和临时头脑风暴会议。页面的单一任务是：让成员通过同一个房间链接进入一张白板，实时看见彼此的笔画、光标和在线状态，并能在结束时导出成果。

## 方案比较

1. **托管实时服务**：跨设备上线最快，但需要账号、密钥、配额与持续外部服务，挑战项目无法开箱即用。
2. **纯 WebRTC**：数据可以点对点传输，但多人网状连接、信令和断线恢复明显超出本项目所需。
3. **WebSocket 房间服务 + BroadcastChannel 回退（采用）**：本机启动时提供真正跨设备房间同步；GitHub Pages 上自动使用同浏览器多标签协作，无需配置也能体验完整交互。

## 视觉系统

- 描图纸蓝 #dcecff：页面底纸和协作空间
- 墨线黑 #17242d：工具、结构与正文
- 标记橙 #ff6b35：当前动作、警示与主按钮
- 会议紫 #6948d9：房间信息、远端协作者和焦点
- 荧光黄 #f6ef72：选择、在线状态和便签感提示
- 纸白 #fffef8：画布、弹层与导出底色
- 展示字：Arial Black / Microsoft YaHei，用于命题和房间编号
- 正文字：Segoe UI / Microsoft YaHei，用于工具与说明
- 数据字：Cascadia Mono / Consolas，用于坐标、连接状态和成员编号

## 标志性元素

白板像一张铺在会议桌上的半透明描图纸：画布四角有图纸编号，远端光标会留下短暂的彩色套色尾迹；协作者加入时，其颜色会落进右上角的“会议针盘”。这一处动态承担全部视觉记忆点，其他界面保持安静而工具化。

## 交互模型

- 工具：画笔、荧光笔、直线、橡皮；颜色和粗细可调整
- 指针按下后创建临时笔画，移动时只刷新本地预览并节流发送点位，抬起后提交完整笔画
- 橡皮通过碰撞笔画包围盒删除整条笔画，删除操作同样作为房间事件广播
- 本地撤销/重做只针对自己的最近操作，广播相应新增或删除，避免篡改他人历史
- 清空房间必须二次确认；导出 PNG 使用纸白背景，不包含协作者光标和界面
- 房间号存放在 URL 查询参数，复制链接后可让其他浏览器进入同一房间

## 同步协议

消息统一包含 `v`、`type`、`room`、`clientId` 和 `ts`。服务端接受 `join`、`stroke:start`、`stroke:points`、`stroke:commit`、`stroke:remove`、`board:clear`、`cursor` 与 `ping`；向客户端发送 `snapshot`、`presence`、相同的绘图事件和 `pong`。

服务端按房间保留已提交笔画，最多 2,000 条；每条最多 4,000 个点，每条消息最大 256KB。临时笔画在成员离开时清理。新成员加入后先收到快照，再接收增量。服务端不落盘、不使用账号，进程重启会清空房间。

## 部署与回退

- `npm start` 启动 HTTP + WebSocket 同源服务，适合本机和局域网真实多人协作
- GitHub Pages 无法承载 WebSocket 服务，前端会尝试配置的 `?ws=` 地址；不可用时切换到 BroadcastChannel
- BroadcastChannel 仅同步同一浏览器、同一站点下的标签页，界面明确显示“本机协作”而不是伪装为互联网在线
- WebSocket 断线采用指数退避；恢复后重新加入并以服务端快照对齐

## 非功能要求

- 指针移动渲染保持约 60fps，网络点位发送最多约 30 次/秒
- 同一房间目标 20 名在线成员、2,000 条已提交笔画
- 所有 WebSocket 消息做类型、大小、房间号、字段和数值范围校验
- 不执行远端 HTML，不接受文件上传，不记录 IP、姓名或消息内容到磁盘
- 390px 布局将工具架变为横向可滚动栏，画布保留至少 420px 高度
- 键盘焦点可见，按钮具备可读名称，并尊重减少动态效果

## 验收标准

- 单标签可以使用四种工具绘制、撤销、重做、二次确认清空和导出 PNG
- 两个相同房间标签页能实时同步笔画、删除、清空、光标和在线成员
- 不同房间互不串线，新成员收到当前快照
- WebSocket 服务能处理加入、快照、增量、presence、断线和非法消息
- GitHub Pages 显示本机协作回退；本地服务显示 WebSocket 已连接
- 断线后保留本地操作并自动尝试重连，状态文案准确
- 桌面和窄屏无页面级横向溢出，画布坐标缩放正确
- 追踪器显示 42/100，第 042 项链接和完成态正确
