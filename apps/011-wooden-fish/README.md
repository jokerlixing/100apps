# 🐟 #011 电子木鱼 · Wooden Fish

> 禅意解压神器：敲木鱼功德+1，Canvas 粒子飘字特效，Web Audio 合成木鱼音，自动敲击，功德本地永存。

## ✨ 功能

- 点击/空格敲木鱼，功德+1（12% 概率触发彩蛋文案：功德+10/心诚则灵/佛光普照/无量功德）
- **Canvas 粒子系统**：金色光点上飘 + 功德文字渐隐，每次敲击 6 光点 + 1 飘字
- 木鱼"笃"声：Web Audio 振荡器 620Hz→140Hz 快速降频合成（无外部文件）
- 自动敲击模式（1-10 次/秒可调），挂机积功德
- 祈福按钮：程序员的愿望随机飘出（愿代码无bug/愿需求不改…）
- 功德累计 + 历史峰值，localStorage 持久化；音效可静音

## 🛠 技术栈

纯 HTML / CSS / JS 单文件，零依赖。

**核心知识点——Canvas 粒子系统（游戏特效的底层套路）：**
- 粒子池：每粒子有位置/速度/重力/寿命/衰减率，属性驱动行为
- `requestAnimationFrame` 统一重绘循环，寿命尽头 splice 回收
- 布局用 CSS 定位，特效层用 Canvas 叠加（pointer-events:none 穿透点击）
- devicePixelRatio 缩放保证高清屏粒子不糊

**音效合成**：正弦波起始高频快速指数降频（620→140Hz）+ 快速衰减包络 ≈ 打击乐"笃"声——降频打击乐公式。

## 🚀 运行

直接打开 `index.html`，或访问 GitHub Pages。
