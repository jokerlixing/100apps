# TAPE/48 键盘钢琴

100 个应用挑战的第 48 个项目。一台完全运行在浏览器里的双八度排练磁带机：使用电脑键盘、鼠标或触屏演奏，把即兴按真实时间录下来，再立即回放。

## 功能

- C4 到 B5 共 24 颗琴键，两组完整八度
- 电脑键盘、鼠标、触屏与无障碍按钮输入
- 纸槌钢琴、电光键盘、房间风琴三种 Web Audio 合成音色
- 主音量与延音踏板控制
- 按真实起止时间录制音符，支持停止、回放、暂停、继续和清空
- 磁带式音符时间轴与同步回放磁头
- 最近一次有效录音自动保存在当前浏览器
- 页面失焦自动释放声音，避免音符长鸣
- 响应式布局、清晰焦点与 reduced-motion 支持

## 电脑键位

| 音域 | 白键与黑键映射 |
| --- | --- |
| C4—B4 | `Z S X D C V G B H N J M` |
| C5—B5 | `Q 2 W 3 E R 5 T 6 Y 7 U` |

传输控制：`F8` 开始录制，`Esc` 停止，`Space` 回放/暂停，`Delete` 清空（需要二次确认）。

## 本地运行

在仓库根目录启动静态服务器：

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

然后访问：

```text
http://127.0.0.1:8765/apps/048-keyboard-piano/
```

## 测试

```powershell
node --test apps/048-keyboard-piano/piano-core.test.js
```

项目不加载远程字体、音色采样或第三方库。声音由 Web Audio 实时合成；录音只保存音符事件和时间，不读取麦克风，也不会离开浏览器。
