# 🎯 #008 随机点名器 · Random Picker

> 课堂点名/年会抽奖场景：名单管理、老虎机滚动动画、已点不重复、点名记录，crypto 级公平随机。

## ✨ 功能

- 名单一行一个，自动去空行，localStorage 持久化
- 老虎机滚动动画（先快后慢，1.8 秒定格）+ 中奖双音上扬音效
- "已点不重复"模式：抽完全员自动提示重置；关闭则可重复抽
- 名单洗牌（Fisher-Yates，安全随机）
- 本轮点名记录（名字 + 时间），一键重置本轮

## 🛠 技术栈

纯 HTML / CSS / JS 单文件，零依赖。

**知识点呼应：**
- 随机源复用 #005 的方案：`crypto.getRandomValues` + 拒绝采样——点名公平性也值得密码学随机（`Math.random` 可被预测/复现）
- 动画用 `requestAnimationFrame` + 二次缓动（`prog²`）实现减速定格，不依赖 CSS 动画时间线，可精准控制结束时机

## 🚀 运行

直接打开 `index.html`，或访问 GitHub Pages。
