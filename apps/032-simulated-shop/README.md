# #032 小满百货（模拟电商列表页）

一个完整演示“发现商品 → 筛选排序 → 加入购物车 → 计算订单”的本地电商列表页。以生活百货为主题，不依赖外部图片或接口，打开 `index.html` 即可使用。

## 功能

- **商品陈列**：12 件本地商品数据，包含分类、价格、评分、销量、库存与独立视觉色板
- **组合筛选**：关键词搜索、分类切换、最高价滑杆可同时生效
- **五种排序**：编辑精选、价格升降序、评分优先、销量优先
- **购物车**：加入、增减数量、移除、二次确认清空、库存上限
- **订单计算**：商品小计、运费、满 199 元免邮进度与订单总价
- **状态持久化**：购物车存入 localStorage，刷新页面自动恢复并校验数据
- **完整状态**：筛选无结果、空购物车、库存不足、模拟结算均有明确反馈
- **响应式与可访问性**：桌面/平板/手机布局、可见键盘焦点、Escape 关闭抽屉、ARIA 动态播报

## 核心知识点：派生状态

```text
原始商品 PRODUCTS
      +
搜索 / 分类 / 最高价 / 排序状态
      ↓
deriveProducts()
      ↓
当前商品列表

购物车只存 {id, qty}
价格与库存始终从 PRODUCTS 读取，避免存档中的旧价格污染订单。
```

运费规则：订单未满 199 元收取 12 元运费，满 199 元免运费。结算按钮仅用于交互演示，不会发起真实支付。

## 视觉设计

“小满百货”采用复古价格标签语言：瓷白纸张、钴蓝、柿子橙、柠檬黄与薄荷绿。商品图由 CSS 色块和字符图形生成，购物车设计成右侧抽出的收银小票，页面零外部资源依赖。

## 技术栈

纯 HTML / CSS / JavaScript 单文件，无框架、无构建步骤、无网络请求。
