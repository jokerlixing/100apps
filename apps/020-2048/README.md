# #020 2048 (数字合并游戏)

经典 2048 游戏：方向键移动方块，相同数字相撞合并，目标达到 2048。

## 功能
- **键盘**：↑↓←→ / WASD 移动，R 新局
- **移动端**：画布滑动手势 + D-pad 双触控
- **计分**：合并产生分数 + 最高分 localStorage
- **胜负判定**：达到 2048 胜利（可继续），无路可走 Game Over
- **动画**：新生方块 pop 弹出，合并方块 scale 一下
- **响应式**：棋盘 aspect-ratio 自适应，tile 字号随格子大小算

## 核心知识点：矩阵旋转算法（2048 精髓）
```
四方向移动归一为"左移"——只写一个 slideLeftRow() 函数通吃：

左移  = 原矩阵 → 每行 slideLeft
右移  = 每行翻转 → slideLeft → 翻转回来
上移  = 转置 → 每行 slideLeft → 转置回来
下移  = 转置 → 每行翻转 → slideLeft → 翻转 → 转置

合并规则（防连击）：
  [2,2,2,2] 左移 → [4,4,0,0]（不是 [8,0,0,0]）
  —— 每格只能合并一次，i++ 跳过已合并的下一个

canMove 检测：有空格 / 相邻同值即可移动
```

## 配色
深色主题适配的经典 2048 配色：2→16 由暗到亮，64 起红，128-512 黄系，1024 青绿，2048 发光绿，4096+ 蓝金。

## 技术栈
纯 HTML/CSS/JS 单文件，无依赖。
