# #038 PULSE/38 在线问卷系统

一个面向工作坊主持人、产品研究者和小团队的零依赖问卷工具。它把问卷设计、受访者预览、分享填写和结果统计放进同一条“研究脉冲”工作流。

直接打开 index.html 即可使用，无账号、无后端、无外部依赖。

## 功能

- **问卷设计**：编辑标题与说明，实时保存草稿
- **四种题型**：单选、多选、短文本、1–5 评分
- **题目管理**：新增、修改、必答开关、上下移动、选项管理和二次确认删除
- **实时预览**：设计页右侧同步展示受访者看到的问卷
- **URL 分享**：将规范化问卷编码进 Hash，复制链接即可跨设备打开
- **填写体验**：答题进度、必答校验、提交回执和再次填写
- **结果分析**：选择题比例、评分分布与均值、文字回答列表、答卷脉冲带
- **本地持久化**：问卷草稿与答卷保存在 localStorage
- **安全与恢复**：文本统一 HTML 转义，非法分享载荷和损坏存储自动回退
- **响应式与可访问性**：桌面/移动布局、键盘焦点、语义表单与减少动态效果

## 静态分享边界

这个应用部署在 GitHub Pages，不包含数据库或服务端：

1. 分享链接携带的是问卷结构，因此题目可以跨设备打开。
2. 答卷保存在填写者当前浏览器，不会自动回传给创建者。
3. 结果页只统计当前浏览器中、问卷 id 相同的答卷。
4. 分享链接不包含已有答卷，也不会上传任何数据。

这个边界会在分享面板、填写页和结果页持续提示，避免把本地演示误解成云端问卷平台。

## 数据结构

~~~javascript
{
  survey: {
    id,
    title,
    description,
    questions: [{ id, type, title, required, options }]
  },
  responses: [
    { id, surveyId, submittedAt, answers: { [questionId]: value } }
  ]
}
~~~

## 视觉设计

界面取材自研究工作台和光学答题卡：深紫结构承载问卷逻辑，橙色表示正在传递的答案，青色和淡紫组成统计信号，柠檬黄用于选择与提示。结果页的“答卷脉冲带”让每份提交变成一个可见圆点，是贯穿整个应用的标志性元素。

## 技术栈

纯 HTML / CSS / JavaScript 单文件，无框架、无构建步骤、无网络请求。
