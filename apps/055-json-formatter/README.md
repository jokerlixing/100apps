# SPEC/55 · JSON 格式化工具

一座完全在浏览器里工作的 JSON 数据标本台。它可以格式化、压缩和下载标准 JSON，把语法错误换算成可跳转的行列位置，并把有效内容展开成可搜索、可折叠、可复制路径的结构树。

## 功能

- 粘贴、拖放或选择 `.json` / 纯文本文件，单个文件最大 2 MB
- 输入后自动校验，并显示错误行、列、上下文和插入符号
- 一键跳到错误字符，支持 2 空格或 4 空格格式化
- 压缩为单行、复制当前文本、下载格式化文件
- 按对象键名或基础值搜索，循环定位最多 100 个结果
- 单节点展开/收起、全部展开/收起，复制任意节点的 JSONPath
- 展示节点数、最大深度、叶值数和 UTF-8 体积
- 草稿不超过 250 KB 时自动保存在当前浏览器
- 响应式桌面/手机布局、清晰键盘焦点和减少动态效果支持

## JSON 规则与隐私

应用使用浏览器原生 `JSON.parse`，因此只接受标准 JSON：对象键必须使用双引号，不支持注释、单引号、`NaN`、`undefined` 或尾随逗号。对象、数组、字符串、数字、布尔值和 `null` 都可以作为根节点。

所有解析、搜索、格式化和导出都在当前页面完成，不会上传内容。为避免大内容拖慢页面，结构树一次最多渲染 2,800 个可见节点，全部展开最多记录 2,400 个容器节点；搜索和收起分支仍可继续定位大型结构。

## 使用方式

1. 粘贴 JSON，或点击“打开文件”/把文件拖进编辑区。
2. 语法通过后按需要格式化、压缩、复制或下载。
3. 在结构树搜索键名或值，点击节点查看并复制 `$` 开头的 JSONPath。
4. 语法失败时点击“定位到错误”，直接选中解析器报告的位置。

编辑器快捷键：

- `Ctrl/Cmd + Shift + F`：按当前缩进格式化
- `Ctrl/Cmd + Shift + M`：压缩为单行
- 树节点聚焦后使用 `Enter` / `Space` 切换展开，`←` / `→` 收起或展开

## 本地运行

从仓库根目录启动静态服务器：

```bash
python -m http.server 8000
```

然后访问：

```text
http://127.0.0.1:8000/apps/055-json-formatter/
```

## 测试

```bash
node --test apps/055-json-formatter/json-core.test.js
node --check apps/055-json-formatter/json-core.js
node --check apps/055-json-formatter/app.js
```

核心测试覆盖有效/无效解析、CRLF 行列换算、错误上下文、格式化与压缩、结构统计、深度保护、JSONPath 转义、搜索限制，以及 HTML 形态字符串的纯文本预览。

浏览器 QA 覆盖示例、搜索定位、全部展开/收起、错误跳转、格式化/压缩、文件导入、下载、1280px 桌面与 390px 手机布局、横向溢出和控制台错误。

## 文件

- `index.html`：语义结构、控件和无障碍状态区域
- `styles.css`：SPEC/55 数据标本台视觉与响应式布局
- `json-core.js`：可独立测试的解析、统计、路径和搜索核心
- `json-core.test.js`：Node 内置测试套件
- `app.js`：浏览器状态、DOM 树、文件、剪贴板、下载和草稿逻辑
