# App #040 PRESS/40 图片压缩工具设计说明

## 产品定位

面向需要快速整理作品图、活动照片和网页素材的独立创作者。页面的单一任务是：把一组过大的图片留在本机完成压缩，并清楚展示每张图片压缩前后的尺寸、体积和节省比例。

## 方案比较

1. **像素压片室（采用）**：借用暗房接触表、压片机和曝光刻度，把上传、参数与前后对比连成同一套语言。
2. **工程性能仪表盘**：数据准确，但容易让普通用户面对过多指标，图片本身反而退居次位。
3. **通用云端上传器**：操作熟悉，却会弱化“文件不离开浏览器”这一核心价值。

## 视觉系统

- 暗房薰衣草 #eee9ff：页面背景与接触表底板
- 深靛墨 #202044：正文、边框和机器结构
- 冲洗玫红 #ff5c8a：压缩动作、处理中和错误
- 显影薄荷 #79dfbd：完成、节省体积和结果区域
- 曝光黄 #f5d45f：焦点、刻度与警示
- 纯白 #ffffff：图片卡、控件和预览窗口

- 正文字：Segoe UI / Microsoft YaHei，用于设置和说明
- 数据字：Cascadia Mono / Consolas，用于像素、字节与文件格式

## 标志性元素

首屏是一台“像素压片机”：长条质量刻度穿过上下两块压板，滑杆改变时，中间间距和输出提示同步变化。队列使用数码接触表布局，每张图片都有原片与压片两个窗口。

## 文件与压缩模型

队列项包含 id、File、原图 Object URL、原始尺寸、状态、输出 Blob、输出 Object URL、输出尺寸和错误。支持 JPEG、PNG 与 WebP，每次最多 20 张、单张不超过 25MB；同名、同体积、同最后修改时间的文件视为重复。

压缩时使用 createImageBitmap 解码并绘制到离屏 Canvas；若浏览器不支持，则回退到 Image。最大宽度只缩小不放大，保持原始纵横比。自动格式保留 JPEG/PNG/WebP；显式选择 JPEG 或 WebP 时质量参数生效，PNG 为无损导出。JPEG 透明区域以白色填充。

## 生命周期与隐私

- 图片只存在于当前标签页内存，不写入 localStorage，也不发送网络请求
- 设置项可持久化，文件与压缩结果在刷新后清空
- 删除、重新压缩或离开页面时释放 Object URL
- 设置改变后已有结果标记为待重新压缩，避免误下载旧参数结果
- 下载由用户主动触发，批量下载逐个生成本地文件

## 验收标准

- 点击、拖放和测试样片都能进入同一队列
- 非支持格式、超大文件、重复文件和超过数量上限均给出明确提示
- JPEG/WebP 质量、PNG 无损、最大宽度和不放大规则正确
- 前后预览、体积、像素尺寸、节省比例与汇总统计正确
- 单张和批量下载文件名带 compressed 后缀
- 设置改变会使现有结果失效，重新压缩后恢复
- 所有图片处理留在本机，界面持续展示隐私边界
- 桌面与 390px 手机布局无横向溢出，键盘焦点清楚并尊重减少动态效果
- 追踪器显示 40/100，第 040 项链接和完成态正确
