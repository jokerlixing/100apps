# #025 汇率换算器 (Currency Exchange)

最新参考汇率换算：16 币种互转 + 双数据源容错 + 汇率速查表 + 离线缓存。

## 功能
- **双向换算**：FROM/TO 两个下拉选币种，输入金额即时换算
- **🔄 一键交换**：币种互换（金额结果也跟着换）
- **16 种常用货币**：人民币/美元/欧元/日元/港币/英镑/韩元/新元/澳元/加元/泰铢/林吉特/瑞郎/卢布/新台币/越南盾
- **快捷金额**：100/500/1000/5000/10000 一键填入
- **汇率速查表**：1 基准币兑 8 大货币 + 反向汇率
- **主数据源**：[Frankfurter v2](https://frankfurter.dev/)（聚合 84 家央行，免 key、无日/月配额）
- **备用数据源**：[ExchangeRate-API Open Access](https://www.exchangerate-api.com/docs/free)（主源失败时自动切换）
- **准确标识**：显示数据所属日期、实际来源，以及联网/备用/缓存状态；不再将每日参考汇率误称为实时行情
- **缓存策略**：6 小时本地缓存，联网失败时回落到最近一次可用数据

## 核心知识点：汇率交叉计算
```
API 只给一份 CNY 基准表：rates = {USD: 0.14, EUR: 0.13, ...}
  含义：1 CNY = rates.USD 美元

任两币种换算（交叉汇率）：
  amount × (rates[to] / rates[from])
  
例：100 USD → JPY
  = 100 × (rates.JPY / rates.USD)
  
——一份表通吃全部 N² 币种对，无需逐对请求

数据获取四段式：
  6h 内       → 直接用缓存（秒开）
  缓存超时    → 请求 Frankfurter 最新参考汇率
  主源失败    → 自动切换 ExchangeRate-API
  两个源均失败 → 回落过期缓存（离线可用）
```

> 汇率用于信息参考和金额估算，不包含银行买卖价差，也不适合交易或结算。免费免密钥数据源均不是逐笔实时行情。

## 细节
- 结果保留完整数值和千分位；交换币种时使用未舍入原值，避免“万/亿”缩写造成金额失真
- 结果框只读绿色区分输入
- 移动端交换按钮自动旋 90°（纵向布局）
- 汇率行显示联网/备用/缓存状态 + 数据日期 + 数据来源
