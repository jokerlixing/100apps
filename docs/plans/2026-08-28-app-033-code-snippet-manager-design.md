# App #033 代码片段管理器设计

## 目标

为日常写代码的人提供一个完全本地的片段档案柜。页面的唯一任务是：让用户在十秒内找到、阅读并复制一段曾经保存的代码。

## 方向比较

1. 深色 IDE：熟悉且适合代码阅读，但容易与任何在线编辑器长得一样。
2. 纯卡片收藏夹：轻巧、适合浏览，但长代码的阅读和管理体验较弱。
3. **代码样本柜（采用）**：以实验样本卡和实体档案柜为视觉母题，浅色索引区搭配单块深色代码阅览台，兼顾辨识度与可读性。

## 视觉系统

- 品牌：INDEX/33 · Code Specimen Cabinet
- 色彩：档案灰 `#E8EDF0`、墨蓝 `#102A36`、钴蓝 `#2364E8`、安全橙 `#FF5C35`、标记黄 `#DFFF4F`、代码黑 `#111820`
- 字体：标题使用 Arial Black / 微软雅黑粗体，界面正文使用 Segoe UI / 微软雅黑，代码与数据使用 Cascadia Code / Consolas
- 视觉签名：片段列表是一叠带语言页签、编号与“装订孔”的档案卡；代码详情区像一块嵌入桌面的样本观察窗
- 动效：只保留选中卡片滑入、复制成功反馈和编辑对话框过渡；支持减少动态效果

## 页面结构

```text
┌──────────────────── INDEX/33 顶栏 ───────────────────┐
│ 品牌 / 当前片段统计                         + 新建片段 │
├──────────────────── 检索工作台 ──────────────────────┤
│ 搜索       语言筛选       仅收藏              排序    │
├───────────────┬─────────────────────────────────────┤
│ 片段档案卡列表 │ 片段标题 / 标签 / 收藏 / 编辑 / 删除 │
│ [JS] 001      │ ┌──────── 深色代码观察窗 ─────────┐ │
│ [CSS] 002     │ │ 行号 + 本地语法高亮             │ │
│ [PY] 003      │ └─────────────────────────────────┘ │
│               │ 描述 / 创建与更新时间              │
└───────────────┴─────────────────────────────────────┘
                    新建/编辑时打开居中档案表单
```

## 功能与数据流

- 内置 7 个可直接使用的示例片段，覆盖 JavaScript、TypeScript、Python、CSS、HTML、SQL 和 JSON。
- 搜索标题、说明、标签和代码内容；可叠加语言筛选与“仅收藏”。
- 排序支持最近更新、名称 A–Z、最早归档。
- 新建和编辑共用一套表单：标题、语言、标签、说明和代码。
- 支持选择详情、收藏、复制代码、编辑和二次确认删除。
- 使用轻量本地 tokenizer 对关键词、字符串、注释、数字、HTML 标签和 CSS 属性着色，并生成行号。
- 仅把清洗后的片段数组存入 `localStorage`；加载时校验 ID、语言、字符串字段和时间。
- `/` 聚焦搜索，`N` 新建片段，`Escape` 关闭编辑框。

## 异常与空状态

- 标题或代码为空时阻止保存，并把焦点移到对应字段。
- 搜索没有结果时保留筛选条件，提供一键重置。
- 删除全部片段后展示“建立第一张样本卡”的入口，空数组也会被持久化。
- 剪贴板 API 不可用时自动使用本地文本域回退复制。
- 损坏的本地数据会回退到默认样本，不影响页面启动。

## 验证标准

- 组合搜索、语言筛选、收藏筛选和三种排序结果正确。
- 新建、编辑、收藏、复制、删除和刷新恢复均可完成。
- 高亮输出始终先转义用户代码，不允许代码内容成为 HTML。
- 桌面、平板和手机无横向溢出，移动端详情区位于列表下方。
- 关闭的表单不可点击或获得焦点；键盘焦点和动态提示清晰。
