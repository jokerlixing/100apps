# App #032 模拟电商列表页设计

## 目标

为 100 Apps Challenge 制作一个无需后端、可完整演示商品发现与购物车流程的单页应用。页面的唯一任务是：让用户快速找到一件生活好物并加入购物车。

## 方向比较

1. 时装画报商城：视觉表现力强，但严重依赖外部摄影资源，离线稳定性差。
2. 数码产品商城：筛选维度自然，但容易做成常见的深色仪表盘模板。
3. **小满百货（采用）**：以彩色生活用品为主题，商品视觉由本地 CSS 与字符图形完成，轻量、稳定且容易形成独特品牌感。

## 视觉系统

- 品牌：小满百货 / XIAOMAN GENERAL STORE
- 主色：瓷白 `#F6F7F1`、墨黑 `#18201D`、钴蓝 `#2457E6`、柿子橙 `#FF6B35`、柠檬黄 `#F4E85B`、薄荷绿 `#63C7A6`
- 字体：标题使用 Arial Black / 微软雅黑粗体，正文使用 Segoe UI / 微软雅黑，价格与编号使用等宽字体
- 视觉签名：每张商品卡都是一张放大的“百货价格标签”；购物车则像一张从右侧抽出的收银小票
- 动效：仅保留商品加入购物车的短促反馈与抽屉过渡；尊重 `prefers-reduced-motion`

## 页面结构

```text
┌──────────────── 顶部营业信息条 ────────────────┐
│ 小满百货                   商品数      购物车(0) │
├───────────────────────────────────────────────┤
│ 生活不必囤，刚好够用。        本周新品价格贴纸    │
├──────────────── 筛选工作台 ──────────────────┤
│ 搜索   分类标签   最高价滑杆              排序  │
├──────────────── 商品网格 ────────────────────┤
│ 商品卡  商品卡  商品卡  商品卡                   │
│ 商品卡  商品卡  商品卡  商品卡                   │
└───────────────────────────────────────────────┘
                         ┌──── 小票式购物车抽屉 ──┐
                         │ 商品 / 数量 / 小计      │
                         │ 免邮进度 / 合计          │
                         └────────────────────────┘
```

## 功能与数据流

- 12 件本地商品数据，包含分类、价格、评分、销量、库存和视觉色板。
- 搜索、分类、最高价与排序共同作用于同一个派生商品列表。
- 排序支持精选、价格升序、价格降序、评分和销量。
- 购物车支持添加、增减数量、删除、清空、库存上限、件数徽标、运费与总价计算。
- 满 199 元免运费，否则运费 12 元；进度条实时展示距离免邮的差额。
- 购物车只保存 `{id, qty}` 到 `localStorage`，加载时会对商品 ID、数量和库存做清洗。
- 演示项目不执行真实支付，结算按钮只给出明确提示。

## 异常与空状态

- 没有筛选结果时展示重置筛选按钮。
- 购物车为空时引导用户继续逛商品。
- 达到库存上限时禁用继续添加并提示。
- `localStorage` 不可用或数据损坏时回退为空购物车，不影响主流程。

## 验证标准

- 桌面与移动端布局无横向溢出，购物车抽屉可正常打开和关闭。
- 搜索、分类、价格和五种排序结果正确。
- 加购、数量变化、删除、清空、库存限制、运费和总价计算正确。
- 刷新后购物车恢复；损坏存储数据不会导致页面报错。
- 键盘焦点清晰，Escape 可关闭抽屉，动态结果具有 `aria-live`。
