# ⌨️ #009 打字速度测试 · Typing Test

> 中/英文模式，60 秒限时，逐字对比高亮，实时 WPM 与准确率，行业标准算法。

## ✨ 功能

- 中文/英文双模式，每个模式 5 段随机文本
- 逐字符渲染：正确绿色、错误红色高亮、当前位光标指示
- 实时统计：WPM、准确率、剩余时间、错字数（200ms 刷新）
- 完成报告：WPM/CPM/准确率/错字/用时 + 分级评语
- 阻止方向键跳位（必须按顺序输入，模拟真实打字）
- 首字符触发计时（时间戳），到时或打完自动结算

## 🛠 技术栈

纯 HTML / CSS / JS 单文件，零依赖。

**核心算法：**
- WPM = 正确字符数 ÷ 5 ÷ 分钟数（"1 词 ≈ 5 字符"是打字测试行业通用标准，中英文一致）
- 每字符一个 `<span>`，输入时 O(1) 更新样式而非全量重排
- 计时用 `Date.now()` 差值（首字符触发），`setInterval` 只负责刷新显示——与番茄钟同款"绝对时间"哲学

## 🚀 运行

直接打开 `index.html`，或访问 GitHub Pages。
