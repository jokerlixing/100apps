# #013 节日倒计时卡片 (Festival Countdown)

多节日倒计时看板：焦点卡实时秒级刷新 + 网格卡片总览 + 自定义节日。

## 功能
- **焦点卡**：最近的节日，天/时/分/秒实时倒计时 + 周期进度条（从上次发生到下次的发生进度）
- **网格卡**：全部节日按远近排序，7 天内红色高亮，当天金色发光
- **预置节日**：元旦/情人节/春节/清明/劳动/端午/中秋/国庆/圣诞/跨年
- **自定义**：任意名称+日期添加，悬停删除，localStorage 持久化

## 核心知识点：Date 与时间计算
```
时间差 = target.getTime() - Date.now()     // 毫秒
天/时/分/秒 = 逐级 Math.floor + 取余
公历节日过期 → 年份+1 自动滚动
农历节日无法公式推算 → 硬编码日期表（春节2027=2/6）
```

## 性能设计
- 每秒只更新焦点卡的 4 个数字（textContent，无重排）
- 小卡片按"天"粒度，每 10 分钟才重渲染一次
- 分层刷新 = 时间类应用的标准做法

## 技术栈
纯 HTML/CSS/JS 单文件，无依赖。
