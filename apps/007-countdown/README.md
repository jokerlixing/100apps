# 📅 #007 倒计时日历 · Countdown

> 多目标日期倒计时：节日一键添加、按紧急度变色（7天内红/30天内橙/远期绿）、自动排序。

## ✨ 功能

- 自定义目标 + 日期，按日期自动排序
- 节日快速添加（元旦/春节/清明/劳动节/端午/中秋/国庆，自动找未来最近一次）
- 紧急度分级变色：≤7天红色 / ≤30天橙色 / 更远绿色 / 已过期置灰
- 特殊状态：今天（🎉）、明天（单独文案）
- localStorage 持久化，首次使用自动加两个示范目标

## 🛠 技术栈

纯 HTML / CSS / JS 单文件，零依赖。

**核心知识点——日期差的时区陷阱：**
- 错误写法：`new Date("2026-10-01")` 按UTC零点解析，东八区是早上8点，`floor` 后可能少一天
- 正确写法：`new Date(y, m-1, d)` 按本地零点构造
- 除法用 `Math.round` 而非 `floor`：夏令时切换会产生 23/25 小时的"天"，round 自动纠偏
- 节日找"未来最近一次"：今年过了就找明年，循环 `getFullYear()` 到 `+1`

## 🚀 运行

直接打开 `index.html`，或访问 GitHub Pages。
