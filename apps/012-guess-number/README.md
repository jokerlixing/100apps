# #012 猜数字游戏 (Guess Number)

经典猜数字游戏，核心演示**二分查找**算法。

## 玩法
- 系统随机想一个 1~100（可切换 500/1000）的数字
- 输入猜测，提示"太大了/太小了"
- 绿色进度条实时可视化剩余可行区间
- 猜错的历史以彩色 chip 展示（红=太大，蓝=太小）
- 每次反馈附带**最优建议值**（当前区间中点）

## 核心知识点：二分查找
```
每次猜测排除一半候选 → log₂(N) 次收敛
1~100   → 最多 7 次
1~500   → 最多 9 次
1~1000  → 最多 10 次
```
游戏里的绿色区间条就是二分查找的"搜索空间"可视化。

## 特性
- 三档难度（100/500/1000）
- 理论最优判定（达到 log₂(N) 次会获 🏆）
- 历史记录智能收缩区间
- 最少次数纪录 + 总局数（localStorage 持久化）
- Enter 快捷提交 / 输入抖动反馈
- 移动端适配（tap-highlight 透明 + 数字键盘）

## 技术
纯 HTML/CSS/JS 单文件，无依赖。
