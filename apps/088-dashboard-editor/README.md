# GRID/88 · 可视化大屏编辑器

一个不依赖框架和远程服务的浏览器大屏编辑器。它把本地 JSON/CSV 数据绑定到 12 列网格中的指标卡、柱状图、趋势图、占比环图与数据表，适合快速制作运营、活动和展示大屏。

## 功能

- 从组件仓点击或拖入五类组件。
- 在画布内拖动组件，或用方向键逐格微调；`Shift + 方向键` 每次移动两格。
- 通过右侧调音台编辑标题、颜色、数据源、字段映射和网格尺寸。
- 粘贴 JSON 数组或带表头 CSV 创建本地数据源。
- 支持撤销/重做、复制、删除、双底色与沉浸预览。
- 自动保存到 `localStorage`，并支持项目 JSON 导入/导出。
- 桌面、平板与手机工作台布局；支持键盘焦点和减少动画偏好。

## 数据格式

JSON 顶层必须是对象数组：

```json
[
  { "区域": "华东", "访问量": 12840 },
  { "区域": "华北", "访问量": 9680 }
]
```

CSV 第一行作为字段名，支持双引号、逗号和双引号转义：

```csv
区域,访问量
华东,12840
华北,9680
```

数据只在当前浏览器中解析和保存，不会上传服务器。浏览器存储可能被清理，重要项目请使用“导出”保存 JSON 备份。

## 本地运行

在仓库根目录启动任意静态服务器，例如：

```powershell
python -m http.server 8080
```

然后打开 `http://127.0.0.1:8080/apps/088-dashboard-editor/`。

## 验证

```powershell
node --test apps/088-dashboard-editor/dashboard-core.test.js
node apps/088-dashboard-editor/qa/browser-smoke.mjs
```

第二条命令会使用本机 Chrome 或 Edge 做桌面、预览和移动端冒烟测试，并将验证截图写入 `apps/088-dashboard-editor/assets/`。
