# #016 Markdown简历生成器 (Resume Maker)

表单填写 → 实时纸张预览 → 打印/导出 PDF / 下载 .md。

## 功能
- **左侧表单 / 右侧纸张**：姓名、求职意向、联系方式（｜分隔）、简介、技能（每行一项）、工作经历、项目与教育
- **迷你 Markdown 解析器**：经历栏支持 `## ### - **粗** *斜* \`代码\` ---`，边打字边渲染
- **纸张质感预览**：米白纸张 + 金色要点 + 深色标题，所见即所得
- **打印导出**：🖨 按钮调起打印（@media print 隐藏 UI 只输出纸张，可另存 PDF）
- **下载 .md**：把表单反向组装成标准 Markdown 文件
- **示例数据**：一键填充完整示例（前端工程师简历）
- **自动保存**：所有输入实时存 localStorage，刷新不丢

## 核心知识点：迷你 Markdown 解析器
```
逐行扫描 → 按行首特征分派（## / ### / - / --- / 空行 / 普通行）
行内处理顺序：转义 HTML → `code` → **bold** → *em*
（code 最先，防止内部被二次污染）

列表状态机：遇 - 开列表，遇非列表项关闭——比全量正则替换更稳
所有用户输入先 esc() 再进 HTML——防注入从源头做起
```

## 细节
- 联系方式支持中英文 ｜ 分隔符，渲染为居中 · 连接
- 打印样式 @media print 隐藏表单/工具栏，只留纸张
- 下载文件名自动取姓名（无姓名则"简历.md"）

## 技术栈
纯 HTML/CSS/JS 单文件，无依赖。
