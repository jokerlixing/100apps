# #040 PRESS/40 图片压缩工具

一个面向独立创作者的纯浏览器批量图片压缩工具。图片进入“数码接触表”后，通过 Canvas 在当前设备完成缩放、格式转换与质量压缩，并展示每张图片的前后预览和节省比例。

直接打开 index.html 即可使用，无账号、无后端、无外部依赖。

## 功能

- **批量导入**：点击选择或拖放 JPEG、PNG、WebP 图片
- **测试样片**：浏览器内生成 1800×1200 合成图，无需个人文件即可体验
- **压缩参数**：自动原格式、JPEG、WebP、PNG，无损与 40–95% 质量范围
- **尺寸约束**：保持原尺寸或限制至 640、1280、1920、2560px，只缩小不放大
- **本地 Canvas 管线**：高质量缩放，JPEG 透明区域自动铺白
- **前后预览**：原图和压缩图并排显示像素尺寸、格式与文件体积
- **汇总统计**：文件数、原始体积、输出体积和总体节省比例
- **下载管理**：单张下载和批量下载，文件名自动添加 compressed 后缀
- **结果失效**：参数改变后释放旧结果，并提示重新压缩
- **响应式与可访问性**：键盘上传入口、清晰焦点、移动端布局和减少动态效果

## 文件与隐私边界

- 图片只存在于当前标签页的浏览器内存
- 文件和结果不会写入 localStorage，不发送任何网络请求
- 刷新页面会清空全部文件与压缩结果
- 输出格式、最大宽度和质量设置会保留
- 删除、重新压缩或离开页面时会释放 Object URL

## 支持与限制

- 支持 JPEG、PNG、WebP
- 最多 20 张图片
- 单张不超过 25MB
- 自动模式保留原格式
- PNG 使用无损导出，质量滑杆不生效
- JPEG 不支持透明通道，透明区域会使用白色背景

## 视觉设计

界面取材自数码暗房和接触表：薰衣草底板承载底片队列，玫红代表正在显影与压缩，薄荷绿表示输出完成，曝光黄用于质量刻度。两块随质量变化的压板构成应用最有记忆点的“像素压片机”。

## 技术栈

纯 HTML / CSS / JavaScript 单文件，使用 File、Blob、Object URL、createImageBitmap、Canvas 和 Download API。
