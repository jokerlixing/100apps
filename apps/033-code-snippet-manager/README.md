# #033 INDEX/33 代码片段管理器

一个完全本地的代码片段档案柜，用于收藏、检索、阅读和复制经常复用的代码。打开 `index.html` 即可使用，无账号、无后端、无外部依赖。

## 功能

- **组合检索**：搜索标题、说明、标签、语言与代码内容
- **语言筛选**：JavaScript、TypeScript、Python、CSS、HTML、SQL、JSON
- **收藏与排序**：仅看收藏，按最近更新、名称或最早归档排序
- **完整 CRUD**：新建、查看、编辑、二次确认删除代码片段
- **安全语法高亮**：关键词、字符串、注释、数字、HTML 标签和 CSS 属性本地着色
- **行号与复制**：代码观察窗自动生成行号，一键复制并提供剪贴板回退方案
- **本地持久化**：片段存入 localStorage，刷新恢复并清洗损坏字段
- **快捷键**：`/` 聚焦搜索、`N` 新建、`Escape` 关闭编辑窗口
- **响应式与可访问性**：桌面双栏、移动端上下布局、可见键盘焦点、ARIA 动态播报

## 核心知识点：先转义，再高亮

```text
用户代码
  ↓ 按行扫描
识别 token（注释 / 字符串 / 关键词 / 数字等）
  ↓
普通文本和 token 分别执行 HTML 转义
  ↓
仅给已转义 token 包裹样式 span
  ↓
安全地写入代码观察窗
```

用户保存的 HTML、标签和脚本只会作为文本显示，不会成为真实 DOM 或被页面执行。

## 数据结构

```javascript
{
  id, title, lang, tags, description, code,
  favorite, createdAt, updatedAt
}
```

localStorage 只保存片段数组；加载时会校验语言、必填字段、标签数量与时间格式。空数组也会正常保存，不会被默认样本重新覆盖。

## 视觉设计

界面取材自实验样本柜和实体索引卡：浅色档案区负责检索，单块深色代码观察窗负责阅读。语言标签、样本编号与卡片“装订孔”构成视觉识别，避免做成常见的全屏深色 IDE。

## 技术栈

纯 HTML / CSS / JavaScript 单文件，无框架、无构建步骤、无网络请求。
