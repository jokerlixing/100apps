# 🚀 100 Apps Challenge · 星哥的一百个应用挑战

> 目标：完成 100 个应用 · 导向：作品集 · 节奏：不设期限，但不停更  
> App #001 = 本挑战的进度追踪器

## 一、什么算"完成"？（完成标准 / Definition of Done）

一个应用要勾"✅ 完成"，必须同时满足：

1. **能被访问**：有可点击的链接（GitHub Pages / Vercel / 本地运行截图也行，但上线更好）
2. **核心功能可用**：不是半成品，核心流程跑得通
3. **有 README**：一段话说明它是什么 + 截图/GIF + 技术栈
4. **提交过代码**：代码在 GitHub 仓库里，commit 历史干净

> 💡 刻意练习 > 完美主义。宁可 10 个 70 分应用，不要 1 个做到一半的 90 分应用。  
> L1/L2 允许"丑但能用"，L3 开始要求"能用且不丑"。

## 二、难度阶梯（5 个 Level）

| Level   | 定位       | 数量   | 说明                                       |
| ------- | -------- | ---- | ---------------------------------------- |
| L1 入门   | 单文件小工具   | 15 个 | 纯 HTML/CSS/JS，一个 index.html 搞定，快速建立手感与信心 |
| L2 进阶   | 交互游戏/工具  | 25 个 | 组件化思维、Canvas、API 调用、本地存储                 |
| L3 前后端  | 全功能应用    | 30 个 | Node/Python 后端 + 数据库 + 用户数据              |
| L4 全栈AI | AI 与完整产品 | 20 个 | 接 LLM API、完整产品闭环、插件/小程序/桌面端              |
| L5 综合   | 大项目      | 10 个 | 多模块组合拳，能当作品集门面                           |

## 三、推荐结构：一个 monorepo 走天下

```
100apps/
├── README.md              ← 你正在看的这个
├── index.html             ← 追踪器（App #001）
├── apps/
│   ├── 002-tomato-timer/  ← 编号-英文短名
│   │   ├── index.html
│   │   └── README.md      ← 每个 App 必写：一句话介绍+截图+技术栈
│   ├── 003-todo-list/
│   └── ...
└── assets/                ← 截图、设计稿
```

**GitHub 工作流：**

- 一个仓库 `100apps`，每个应用一个目录，追踪器放根目录
- GitHub Pages 部署：主路径就是追踪器，`apps/002-tomato-timer/` 直接可访问
- 每个 App 完成时：commit + 在追踪器填链接 + 截图发朋友圈（仪式感是续航燃料）

## 四、阶段目标（每 10 个一个里程碑）

- [ ] **#001–#010**：热身期，全部 L1。目标：找回手感，建立"完成"的肌肉记忆
- [ ] **#011–#020**：加入 L2 游戏与工具，开始注意 UI 细节
- [ ] **#021–#035**：L2 冲刺 + 首个 L3（前后端分离初体验）
- [ ] **#036–#065**：L3 主战场。Node/Python 后端、数据库、用户系统，穿插 L4 AI 应用
- [ ] **#066–#085**：L4 深水区：完整产品闭环、插件、小程序、桌面端
- [ ] **#086–#100**：L5 大项目 + 收官之作 #100《个人作品集网站》串起所有作品

## 五、防弃坑三条铁律

1. **卡住超过 2 小时就简化**：砍功能保完成，写进 README 里记一笔"未来可加"
2. **连续 3 天没碰 = 触发警报**：回追踪器看进度环，从 L1 里挑个最简单的做，重启手感
3. **不追求新技术栈全学会**：用会的栈快速交付，新栈留到 L4/L5 再刻意练

## 六、追踪器使用说明

- 打开 `index.html` 即用，数据存浏览器 localStorage
- 点卡片上的状态按钮：未开始 → 进行中 → 完成 → 未开始（循环）
- 🔗 按钮填部署链接，完成后卡片可点击"访问 ↗"
- 支持搜索、按难度/状态筛选、添加自定义点子
- **定期点右上角"导出备份"**，JSON 文件留好，换浏览器可手动恢复
- 重置会清空全部进度，操作前记得先备份

## 七、技术栈参考（点子库已覆盖）

- **前端**：HTML/CSS/JS → Vue/React（L3 起推荐）
- **后端**：Node.js (Express) / Python (FastAPI/Flask)
- **数据库**：SQLite 起步 → MySQL/PostgreSQL
- **AI**：大模型 API（对话/写作/OCR/语音）
- **部署**：GitHub Pages / Vercel / Netlify（免费）
