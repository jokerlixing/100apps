# App 081 · WAVE/81 直播弹幕系统设计

## 产品目标

WAVE/81 是一个可直接部署到 GitHub Pages 的模拟直播间。观众进入“天台声场”后，可以在舞台画面上发送滚动、顶部或底部弹幕，在聊天侧栏查看实时消息，用掌声、爱心和火焰表达反应，并在多个浏览器标签页之间看到同步互动。

项目的单一任务是：在没有后端、账号和真实视频源的前提下，完整演示一个可信、可操作的实时直播互动闭环。页面必须诚实标明这是模拟信号，不伪装成真实在线服务。

## 方案比较与结论

1. 纯视觉弹幕演示：实现最快，但缺少聊天、设置和实时同步，无法体现“系统”。
2. 静态站点 + 本地实时总线：通过定时事件、`BroadcastChannel` 和 `storage` 回退模拟直播，既适合 GitHub Pages，又能覆盖完整互动。采用此方案。
3. WebSocket 后端：更接近生产环境，但会引入部署、鉴权、滥用防护和持久化，超出单项目范围。

## 体验结构

```text
┌ WAVE/81 / LIVE SIGNAL ─────────── 场次状态 / 观众数 ┐
│ ┌────────────────────────────┐ ┌───────────────┐ │
│ │  天台声场模拟画面            │ │  LIVE CHAT    │ │
│ │  直播状态 + 时间码            │ │  消息流         │ │
│ │  三轨弹幕 + 反应粒子           │ │  输入 + 发送     │ │
│ │  播放 / 弹幕 / 影院 / 音量      │ │  快捷反应         │ │
│ └────────────────────────────┘ └───────────────┘ │

│ 节目单 / 系统说明 / 键盘快捷键                         │

```

桌面端采用舞台与聊天 7:3 分栏；窄屏时聊天移到舞台下方，输入框保持可见，控制台改为可横向浏览的紧凑布局。

## 视觉方向

主题来自转播车里的老式信号台，而不是通用的霓虹 SaaS 面板：外壳是暖灰金属，画面区域是深墨绿，状态以真实广播语义编码。

- Console bone `#d8d4c5`：页面底材与实体控制台
- Camera black `#111817`：直播画面与主要文字背景
- Oxide red `#d54832`：唯一的 ON AIR 警示色
- Meter amber `#f1ad3d`：电平、选中态与时间码
- Signal teal `#55b8aa`：成功、连接和辅助信息
- Paper white `#f3f0e7`：深色表面的主文字

标题使用窄体工业字体栈 `Bahnschrift SemiCondensed / Arial Narrow`，正文使用 `Microsoft YaHei / PingFang SC`，时间码和读数使用 `Cascadia Mono / Consolas`。视觉签名是横跨舞台的“信号扫描线”：它既是模拟画面的运动层，也是弹幕轨道的隐形基准。所有动画在 `prefers-reduced-motion` 下关闭。

## 功能与数据流

`danmaku-core.js` 提供无 DOM 的消息标准化、颜色白名单、轨道分配、观众数格式化和偏好校验。`app.js` 负责 DOM、定时模拟观众、弹幕动画、聊天列表、舞台状态和本地持久化。

用户发送消息时，输入先经过空白折叠、长度限制和模式/颜色校验；合法消息同时进入聊天与弹幕轨道，并广播到 `wave81-room`。另一个标签页收到消息后只渲染，不再次广播，避免回环。浏览器不支持 `BroadcastChannel` 时使用 `localStorage` 事件回退；单标签页功能不受影响。

模拟消息由固定语料与随机间隔生成，只在直播未暂停且页面可见时高频运行。密度控制每条消息的最小间隔，速度控制滚动时长。弹幕关闭只隐藏舞台覆盖层，不丢失聊天记录。

## 错误处理与可访问性

- 空消息、超长消息和过快重复发送在输入区就地提示。
- 广播通道或本地存储失败时静默降级为单页模式，并更新连接状态。
- 所有按钮提供可见焦点、`aria-pressed` 或明确标签；输入框支持 Enter 发送。
- `D` 切换弹幕，`T` 切换影院模式，`M` 切换静音；焦点在输入框时不触发快捷键。
- 颜色不是唯一状态信号，直播、暂停、连接状态均同时提供文字。

## 验证标准

1. 单元测试覆盖消息清洗、长度/颜色/模式校验、轨道分配、偏好归一和观众数格式化。
2. 浏览器验收覆盖发送三种弹幕、切换弹幕、暂停/恢复、反应按钮、影院模式、刷新后偏好恢复和窄屏布局。
3. 桌面与移动端截图必须无横向溢出、文字遮挡和不可见控件。
4. 根追踪器最终以 WAVE/81 名称、可访问 GitHub Pages URL 和官方完成状态登记，并由追踪器测试锁定。
