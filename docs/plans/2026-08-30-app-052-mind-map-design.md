# App 052 在线脑图编辑器设计

## 产品边界

52 号应用命名为 **LINE/52**，面向需要快速拆解想法、课程和项目的个人用户。页面的单一任务是把一个中心主题整理成可折叠的分支，并随时导出成图片。首版不做账号、多人协作、云同步、附件、自由连线或复杂主题市场；所有内容只保存在当前浏览器。

完成闭环包括：选择节点、添加子节点或同级节点、改名、删除、展开/折叠分支、撤销/重做、拖动画布、缩放、自动保存和导出 PNG。删除操作可立即撤销，根节点不可删除。存储损坏或版本不兼容时回退到示例脑图，并明确提示本地恢复失败。

## 架构与数据流

应用使用无构建步骤的 HTML、CSS 和 JavaScript。`mind-core.js` 维护树结构的纯函数：文本规范化、不可变增删改、折叠、父节点查询、文档校验和可见树布局；它同时通过 CommonJS 与浏览器全局导出，便于 Node 内置测试运行器覆盖。

`app.js` 负责选择状态、撤销栈、localStorage、SVG 渲染、视口平移缩放和导出。每次编辑先保存旧快照，再生成新树、写入本地存储并重绘；撤销与重做最多保留 50 步。布局采用从左到右的层级树：叶节点占据独立行，父节点垂直居于可见子节点之间；折叠分支不会参与布局，但会在站牌上显示隐藏节点数。

## 界面与视觉

视觉主题是“地铁线路控制台”，不是通用白色卡片式后台。中心主题是换乘总站，一级分支各自获得固定线路色，曲线连线像轨道，子节点是站牌。编辑区占据页面主体，左侧是调度台：节点操作、当前站名和完整大纲；桌面顶部保留标题、保存状态和导出，手机端调度台叠到画布上方。

色彩令牌：制图蓝 `#dbe9f6`、图纸白 `#f7fbff`、深海墨 `#142b3b`、线路蓝 `#2f5bd3`、信号红 `#ef5b4d`、换乘黄 `#f2b544`。标题使用 Bahnschrift SemiCondensed / Arial Narrow，正文使用 Segoe UI / Microsoft YaHei，状态与快捷键使用 Consolas。签名元素是贯穿画布的多色“线路”，动效只用于选中站点的短促信号脉冲，并在 `prefers-reduced-motion` 下关闭。

## 交互与无障碍

鼠标或触摸点击站牌选择节点，双击进入改名；空白处拖动平移，滚轮围绕指针缩放。键盘聚焦站牌后可用 Enter 改名、Tab 新建子节点、Delete 删除、空格折叠；全局支持 `Ctrl/Cmd+Z` 与 `Ctrl/Cmd+Shift+Z`。所有主要按钮有文字或可访问名称，状态变化通过 live region 宣告，焦点环具有稳定对比度。

PNG 导出基于当前完整可见脑图，而不是屏幕截图，因此不受用户当时的缩放和平移影响。导出图包含点阵图纸背景、线路和站牌，但不带编辑选中态或控制按钮。

## 验证标准

Node 单元测试覆盖文本清理、增删改、重复 ID、根节点保护、父节点查询、折叠后的可见布局、父节点居中、文档校验和边界计算。浏览器验证覆盖首次示例、增删改、折叠、撤销重做、刷新恢复、拖动缩放、适配画布、PNG 下载、桌面与 390px 手机布局、键盘路径、控制台错误和本地存储损坏降级。
