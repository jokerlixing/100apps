# #015 配色方案生成器 (Color Palette Generator)

基于 HSL 色彩和谐理论的配色工具：五种和谐模式 + 锁色微调 + 三种场景实时预览。

## 功能
- **五种和谐模式**：类比（相邻渐变）/ 互补（强对比）/ 三等分 / 四等分 / 单色（同相不同明度）
- **三滑杆微调**：色相 0-360° / 饱和度 / 亮度，拖动实时重算整组配色
- **锁色机制**：🔒 锁定满意的颜色，再调其余（Coolors 风格核心交互）
- **三种预览**：卡片角色标注 / CSS 渐变 / 完整网页 Demo——所见即所得
- **一键复制** hex 色值（clipboard API + 降级方案）
- **收藏夹**：最多 12 组，点击色点恢复方案，二次确认清空
- **空格键**快速生成随机配色

## 核心知识点：HSL 色彩模型
```
HSL = Hue 色相(0-360°色环) + Saturation 饱和度 + Lightness 亮度

和谐配色 = 色环上的几何关系：
  类比     [0°, 25°, 50°, 75°, 100°]  相邻柔和
  互补     [0°, 180°]                 对比强烈
  三等分   [0°, 120°, 240°]           活泼平衡
  四等分   [0°, 90°, 180°, 270°]      丰富
  单色     同 H，L 错开 ±28%           极简层次

hsl → hex 转换（设计工具通吃）
hex → hsl 反推（恢复收藏用）
```

## 设计细节
- 每张色卡自动按亮度选择文字颜色（L>60 用深字）
- 预览网页 Demo 的导航/hero/按钮/页脚全部用当前配色渲染
- 渐变预览直接给出可复制的 CSS 代码

## 技术栈
纯 HTML/CSS/JS 单文件，无依赖。
