# App #037 SIGNAL/37 个人博客设计说明

## 产品定位

面向持续做项目、写复盘的独立创作者。页面的单一任务是：让作者用 Markdown 快速发布构建笔记，让读者通过搜索、标签和时间归档找到文章。

## 方案比较

1. **独立创作者短波电台（采用）**：文章是一段段持续发出的“创作信号”，标签像频道，能自然连接写作、筛选和归档。
2. **安静文字杂志**：长文阅读友好，但容易落入高反差衬线字体和米色纸张的常见模板。
3. **开发者终端日志**：适合技术内容，但限制了生活、设计和复盘文章的表达范围。

## 视觉系统

- 冰蓝纸面 #edf2ff：页面背景，像工作室墙上的浅色吸音板
- 纯白 #ffffff：阅读和编辑区域
- 深墨 #111b38：正文、边框和高对比结构
- 钴蓝 #2848e8：品牌、频道轨道和主要操作
- 珊瑚红 #ff6557：ON AIR、发布状态和当前频道
- 芒果黄 #ffd452：批注、焦点与草稿标记
- 青绿 #63cbb3：成功反馈与第三种文章强调色
- 展示字：Arial Black / Microsoft YaHei，形成广播海报式标题
- 正文字：Trebuchet MS / Microsoft YaHei，保持中文阅读清晰
- 数据字：Cascadia Mono / Consolas，用于日期、状态和文章编号

## 数据与交互

文章数据包含 id、标题、摘要、标签数组、Markdown 正文、状态、强调色、创建时间和更新时间。首页默认展示已发布文章；搜索会匹配标题、摘要、标签和正文，频道频率尺按标签过滤，归档按年月聚合。点击文章通过 Hash 路由打开阅读层，链接可复制并在刷新后恢复。

编辑层在桌面端左右分栏显示 Markdown 和预览，移动端上下排列。作者可新建、编辑、发布、存为草稿，并通过二次确认删除。数据写入 localStorage，损坏数据自动回退到示例文章。

## Markdown 与安全边界

- 支持一至三级标题、段落、粗体、斜体、行内代码、代码块、引用、无序/有序列表、分隔线和链接
- 所有正文先进行 HTML 转义，再添加受控标签
- 链接仅允许 http、https、mailto 和页内锚点协议
- 标题、摘要、标签和状态统一归一化，文章 id 不直接拼接未转义内容
- 搜索与渲染为空时给出明确下一步

## 验收标准

- 默认文章、搜索、标签筛选、月份归档和草稿筛选正确
- 新建、编辑、发布、草稿、刷新恢复和删除确认正常
- Hash 深链接能打开文章，关闭阅读层能回到列表
- Markdown 特性正确，脚本标签和 javascript 链接不能执行
- 桌面与 390px 手机布局无横向溢出，键盘焦点清楚并尊重减少动态效果
- 追踪器显示 37/100，第 037 项链接和完成态正确
