# #024 房贷计算器 (Mortgage Calculator)

等额本息/等额本金双模式对比 + 剩余本金曲线图。

## 功能
- **三滑杆输入**：贷款总额（10-1000万）/ 年利率（1.0-6.0%）/ 年限（5-30年），快捷按钮一键设置
- **双模式切换**：等额本息（月供固定）/ 等额本金（月供递减）
- **对比表**：月供/首末月供/利息总额/本息合计/总利息差 全维度对比
- **智能建议**：根据利息差和月供压力给出选型建议
- **剩余本金曲线**：SVG 双线对比（金=本息，绿=本金），60 点采样
- 实时计算，滑杆拖动即更新

## 核心知识点：房贷金融数学
```
等额本息（固定月供）：
  A = P·i·(1+i)ⁿ / [(1+i)ⁿ−1]
  P=贷款本金 i=月利率(年利率/12) n=总月数
  每月利息=剩余本金×i，每月本金=A−利息
  特点：前期还的几乎全是利息

等额本金（递减月供）：
  每月本金 = P/n（恒定）
  第k月月供 = P/n + (P−(k−1)·P/n)·i
  特点：总利息少，但前期月供高

利息差 = 本息总利息 − 本金总利息
  100万/30年/3.6% 场景下本金方式省息约 12 万+
```

## 细节
- 曲线采样：n 个月压到 60 点（性能+平滑兼顾）
- 两条曲线长度统一（线性插值对齐）
- 数字格式：万元缩写（123.4万）
- 建议文案动态生成（利息差+月供压力）

## 技术栈
纯 HTML/CSS/JS 单文件。SVG 曲线手绘。
