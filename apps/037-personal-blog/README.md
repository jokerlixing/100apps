# #037 SIGNAL/37 个人博客

一个面向独立创作者的本地个人博客与 Markdown 写作台。首页提供文章列表、全文搜索、标签频道、月份归档和草稿箱；写作台支持实时预览、发布、编辑和本地保存。

打开 index.html 即可使用，无账号、无后端、无外部依赖。

## 功能

- **文章首页**：最新文章广播、文章卡片、字数与预计阅读时间
- **全文搜索**：联合匹配标题、摘要、标签与 Markdown 正文
- **标签频道**：动态统计标签数量并按频道筛选
- **月份归档**：按文章更新时间聚合，快速回看历史内容
- **发布与草稿**：公开文章和草稿箱分开管理
- **Markdown 写作台**：编辑与实时预览双栏布局
- **文章管理**：新建、编辑、发布、存草稿与二次确认删除
- **阅读路由**：使用 Hash 生成可复制的文章深链接，刷新可恢复
- **本地持久化**：文章数据保存在 localStorage
- **响应式与可访问性**：桌面/移动端布局、清晰键盘焦点、ARIA 对话框和减少动态效果

## Markdown 支持

支持以下常用语法：

- 一至三级标题
- 粗体、斜体与行内代码
- 无序列表、有序列表
- 引用、分隔线
- 代码块
- http、https、mailto 和页内锚点链接

## 安全策略

Markdown 正文先进行 HTML 转义，再由解析器添加受控标签。链接只接受明确的安全协议，因此脚本标签会作为文字显示，javascript 等危险链接不会生成可点击地址。

## 数据结构

~~~javascript
{
  posts: [
    {
      id, title, summary, tags, content,
      status, accent, featured,
      createdAt, updatedAt
    }
  ]
}
~~~

状态包含 published 和 draft。搜索、频道、归档与文章列表都从同一份文章状态派生，不重复保存筛选结果。

## 视觉设计

界面取材自独立创作者的短波电台：钴蓝广播台承载主叙事，珊瑚红标记正在播出，芒果黄用于频道选择和创作操作。横向“频率尺”把标签筛选变成调频，让博客的内容组织成为最有记忆点的交互。

## 技术栈

纯 HTML / CSS / JavaScript 单文件，无框架、无构建步骤、无网络请求。
