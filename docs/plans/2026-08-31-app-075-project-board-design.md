# App 075 项目管理看板设计

## 产品边界

App 075 是一张给 3–6 人小团队使用的本地优先冲刺看板，产品名为 **RAIL/75**。它的单一任务是让成员快速看清“谁正在做什么、任务卡在哪一列、下一步该移动到哪里”。本轮交付不伪装登录、云同步或真实多人协作；所有数据保存在当前浏览器，提供 JSON 导入导出以便演示和转移。

核心闭环为：创建任务 → 分配成员和优先级 → 拖动或按钮推进状态 → 搜索/筛选当前工作 → 查看活动记录与完成进度。默认样例是一支正在发布城市骑行路线产品的小团队，让界面从第一次打开就有真实语境。

## 方案选择

采用无依赖静态应用，而不是引入 React 或服务端。纯 HTML/CSS/JavaScript 与仓库现有 GitHub Pages 部署一致，也让拖拽、键盘操作和本地持久化都能直接验收。领域规则拆到 `board-core.js`，浏览器层只负责渲染和事件；这样排序、筛选、迁移、校验和导入可以用 Node 内置测试稳定覆盖。

四列固定为“收件箱、已排期、进行中、已完成”。任务可在列内排序，也可跨列移动；移动到完成列时记录完成时间，移出时清除。鼠标拖拽之外，每张卡提供“向前/向后”按钮，保证触屏与键盘用户不依赖原生拖放。

## 视觉方向

RAIL/75 使用“交通调度蓝图”而不是常见 SaaS 渐变卡片：

- 雾蓝纸面 `#DDE5EA`：主背景与网格底图。
- 海军墨 `#172A3A`：文字、结构线与按钮。
- 信号橙 `#F06A3A`：主要动作、阻塞和拖拽轨道灯。
- 调度蓝 `#2F6E9C`：选择状态、链接和焦点。
- 票据白 `#F7F3E8`：任务卡和弹窗。
- 苔绿 `#4C7B61`：完成与健康状态。

标题使用 `Arial Narrow`/`Bahnschrift Condensed` 的窄体大写，正文使用 `Segoe UI`，编号和元数据使用 `Cascadia Mono`。签名元素是贯穿四列顶部的状态轨道：拖动卡片时目标列亮起信号灯，列标题像站台牌；所有装饰都对应任务流转，不加无意义编号。

桌面为窄侧栏加横向四列工作台；小屏改为顶部概览与可横向滚动的单列宽轨道，保留 300px 以上的卡片可读宽度。动效只用于任务落位和轨道灯，`prefers-reduced-motion` 下关闭。

## 组件与数据流

`board-core.js` 定义版本化状态 `{version, project, members, tasks, activity}`。公开函数负责创建默认数据、清洗导入、创建/更新/删除任务、跨列移动、列内排序、筛选和统计。每次写操作返回新状态并追加一条上限 80 条的活动记录。

`app.js` 从 `localStorage` 读取数据，失败时回退到默认看板并显示可恢复提示。用户操作先经过核心函数验证，成功后统一 `persist → render → announce`；校验失败保留当前界面并把原因写入表单错误或状态区。拖拽只保存任务 ID 和源列，落点换算为目标列中的索引后调用同一个移动函数，因此按钮推进与拖放共享规则。

界面由项目总览、成员筛选、搜索框、四列看板、活动抽屉、任务编辑对话框和数据菜单组成。筛选只影响显示，不改变底层顺序；统计基于全量任务，避免搜索时进度数字跳动。

## 错误与可访问性

任务标题必填且不超过 80 字；说明不超过 300 字；截止日期必须为合法 `YYYY-MM-DD`；成员、优先级和状态必须来自允许集合。导入仅接受不超过 512 KiB 的 JSON，逐项清洗，无法恢复的文件拒绝覆盖当前数据。导出文件不含密钥或外部资源。

所有操作均为真实按钮或带标签的控件；对话框打开后聚焦标题，关闭后返回触发按钮。卡片可聚焦，前进/后退按钮提供非拖拽通道；拖动结果、保存、删除、导入错误通过 `aria-live` 宣告。焦点环与文本对比保持清晰。

## 验收

Node 单元测试覆盖状态清洗、标题边界、成员校验、跨列移动、列内排序、完成时间、筛选与统计。浏览器冒烟覆盖创建、筛选、编辑、推进、拖放、刷新持久化、导出入口、移动端溢出、键盘焦点和控制台错误，并生成桌面/移动截图供 README 和人工复核。
