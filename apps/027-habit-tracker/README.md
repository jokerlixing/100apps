# #027 习惯打卡日历 (Habit Tracker)

GitHub 热力图风格的坚持记录：多习惯管理 + 连续天数 + 半年热力图。

## 功能
- **多习惯管理**：添加任意习惯（自动轮换 emoji 图标），同名去重
- **今日打卡**：大按钮一键打卡/撤销（金色边框→绿色实心）
- **GitHub 热力图**：近 26 周（半年）格子系统
  - 列=周（左旧右新），行=周一到周日
  - 打卡日=饱和绿（发光），未打=深灰，今天=金色描边
  - **点击任意历史格子可补卡/撤销**（漏打卡补救）
  - 月份标签自动生成
- **三项统计**：连续天数 streak / 累计打卡 / 全年完成率
- **streak 算法**：今天没打卡不清零（从昨天起算），断一天才断

## 核心知识点：热力图数据结构
```
数据模型：habit = {id, name, ico, days:{"2026-08-27":1}}

用对象键值对存日期：
  查询 O(1)：days["2026-08-27"] —— 比数组 includes O(n) 快
  删除 O(1)：delete days[dateStr]
  序列化即排序无关（渲染时按格子坐标查）

streak 连续天数（正逆向扫描）：
  从今天往前逐日探测，今天无记录则从昨天起算
  ——"今天还没打"不该把昨天攒的连续清零

热力图布局：
  26 周 × 7 天 = 182 格，flex 列式（列内 7 格纵向排列）
  未来日期透明占位（保持网格对齐）
```

## 技术栈
