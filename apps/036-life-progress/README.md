# #036 LIFE/36 人生进度条

一个把人生、自然周期和个人目标放到同一张“时间地图”上的本地进度应用。设置出生日期与目标年龄后，可以看到精确年龄、已经历天数和尺度内剩余时间；年、月、周、日进度会随本地时间自动校准。

打开 index.html 即可使用，无账号、无后端、无外部依赖。

## 功能

- **人生长尺**：按出生日期与自定义目标年龄计算人生进度
- **精确年龄**：显示年、月、日，以及已经历和尺度内剩余天数
- **自然周期**：年度、当月、本周、今日四种进度实时可视化
- **量化目标**：名称、当前值、目标值、单位、颜色和可选截止日期
- **目标 CRUD**：新建、编辑、快捷增减与二次确认删除
- **动态校准**：今日进度每秒更新，其他周期自动跨界刷新
- **本地持久化**：个人设置与目标数据保存在 localStorage
- **边界处理**：闰年、不同月份天数、周一作为周起点、无效输入提示
- **响应式与可访问性**：桌面/移动端布局、可见键盘焦点、ARIA 状态、减少动态效果

## 核心知识点：用时间区间统一计算进度

~~~javascript
progress = (now - start) / (end - start) * 100
~~~

人生、年度、月份、周和日都转换为 start 和 end 时间区间，再复用同一个计算函数。进度会限制在 0–100%，避免出生日期、目标年龄或系统时间异常时溢出。

周进度以周一 00:00 为起点，月份使用下月 1 日作为终点，因此会自然适配 28、29、30、31 天。人生目标日期对 2 月 29 日做了月末修正。

## 视觉设计

界面取材自测绘图纸和机械标尺：雾蓝网格纸承载人生主尺，朱红游标标记“此刻”，柠檬黄表示已经走过的范围。自然周期与个人目标沿用同一套刻度语言，让长期时间和日常行动能被直接比较。

> 目标年龄仅是用户自定义的可视化尺度，不构成健康建议或寿命预测。
