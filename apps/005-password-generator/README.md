# 🔐 #005 密码生成器 · Password Generator

> Web Crypto 密码学安全随机数生成密码，实时熵值计算与强度分级，可配长度/字符集/排除易混淆字符。

## ✨ 功能

- 长度 8–64 可调，四类字符集自由开关（至少保留一类）
- 排除易混淆字符（`0O1lI` 等），抄写密码不抓瞎
- 实时熵值（bits）与四段强度条：很弱 / 一般 / 较强 / 非常强
- 点击即复制，内存生成、绝无存储
- 每类字符保底出现一个 + Fisher-Yates 洗牌

## 🛠 技术栈

纯 HTML / CSS / JS 单文件，零依赖。

**核心知识点——密码学安全随机：**
- `Math.random()`：伪随机（PRNG），种子可被推断，输出可预测 → 不能用于密码
- `crypto.getRandomValues()`：操作系统级密码学安全随机源（CSPRNG）
- **拒绝采样**：`buf[0] % max` 当 max 不整除 2³² 时会有取模偏差（前面的字符出现概率略高），通过"超出范围就重新抽"消除——密码学代码的严谨之处就在这些细节
- 熵 = 长度 × log₂(字符集大小)，暴力破解成本随熵指数增长
