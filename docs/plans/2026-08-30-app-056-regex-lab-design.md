# App 056 · Pattern Lab 设计说明

## 目标

Pattern Lab 是一款面向学习者和前端开发者的纯前端正则表达式测试器。页面的唯一主任务是让用户在编辑表达式和样本文本时，立即看到匹配位置、捕获组和替换结果。

完成标准：

- 支持 JavaScript 正则语法与 `d g i m s u v y` 标志，非法表达式不会打断页面。
- 测试文本中所有匹配都有可读高亮，当前匹配可在文本和检验带间联动。
- 每个匹配显示序号、范围、完整值、编号捕获组和命名捕获组。
- 常用正则库可一键载入，替换区可实时预览并复制结果。
- 表达式、标志、测试文本和替换字符串只保存在当前浏览器。
- 桌面与移动端都可用，完整支持键盘焦点和减少动效偏好。

## 方案取舍

1. **同步镜像高亮（采用）**：在透明 `textarea` 下放置等尺寸高亮层，共享字体、换行和滚动位置。原生输入体验稳定，无第三方依赖，也适合 GitHub Pages。
2. **`contenteditable` 编辑器**：高亮直接嵌入文本，但光标、撤销和粘贴行为难以稳定。
3. **引入 CodeMirror/Monaco**：编辑功能强，但体积和工程复杂度远超本项目的核心任务。

## 视觉方向

页面以“模式实验台”为题，不使用通用黑色终端外观。背景像冷色实验纸，信息面板像带编号的检验单。

- `paper #F3F6F4`：页面底色
- `surface #FFFFFF`：主工作面
- `ink #17212B`：正文与边线
- `cobalt #2357D8`：结构、焦点与主操作
- `vermilion #F25C3B`：匹配高亮与错误
- `mint #CDEFD8`：成功和辅助状态

标题使用窄体系统无衬线字体，表达式、索引和数据使用 `Cascadia Mono` / `Consolas`，正文使用 `Segoe UI` / `Microsoft YaHei`。

记忆点是右侧的“匹配检验带”：每个匹配是一段带孔位编号的独立纸条，点击后会定位并强调文本中对应命中。这是页面唯一的强装饰元素。

```text
+------------------------------------------------------------+
| PATTERN LAB / 056                 12 MATCHES · 1.4 ms     |
+-----------------------------+------------------------------+
| / expression / [flags]      | MATCH INSPECTION TAPE        |
| preset library              | #01  [12, 24]  "..."         |
+-----------------------------+ #02  [39, 51]  "..."         |
| TEST MATERIAL               | groups / named groups        |
| highlighted textarea       |                              |
|                             |                              |
+-----------------------------+------------------------------+
| REPLACEMENT       live preview / copy                      |
+------------------------------------------------------------+
```

## 架构与数据流

- `regex-core.js` 提供无 DOM 依赖的编译、匹配提取、高亮分段和替换函数，同时支持浏览器与 Node 测试。
- `app.js` 保存 UI 状态，将输入在 90ms 后合并计算，再一次性更新高亮层、统计、检验带和替换预览。
- 编译失败时保留输入，清空旧结果，并在表达式下方显示可修复的错误。
- 为避免结果列表拖垮页面，最多展示 300 个匹配，达到上限时明确提示。测试文本限制为 50,000 字符。
- 本地状态使用带版本的 `localStorage` 键，解析失败则回退到默认样例。

## 验证

- Node 单元测试：标志去重、非法表达式、全局/非全局匹配、零长度匹配、编号/命名捕获组、高亮分段与替换。
- 语法检查：`node --check` 覆盖核心和 UI 脚本。
- 浏览器检查：预设切换、错误恢复、匹配联动、替换复制、刷新恢复、移动布局和无横向溢出。
