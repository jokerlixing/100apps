# App 059 · CUT/59 字幕走片台设计说明

## 目标

CUT/59 是给短视频创作者和独立剪辑者使用的本地字幕时间轴编辑器。页面的单一任务是：让用户把 SRT/VTT 字幕贴合本地视频，在播放预览中逐条校正，然后导出可继续使用的字幕文件。

完成标准：

- 本地选择视频后可播放、暂停、拖动和逐帧近似步进，视频不会上传。
- 可导入 UTF-8 SRT/VTT，也可从空白字幕开始；解析错误给出可修复提示。
- 字幕条目支持新增、删除、复制、拆分、文本编辑和起止时间微调。
- 播放头、视频画面、字幕叠加、字幕列表和总览时间轴保持联动。
- 时长非法、前后倒置和字幕重叠都有明确警告，但不会无提示地改写用户数据。
- 可导出标准 SRT 与 WebVTT；编辑草稿保存在当前浏览器，视频文件不持久化。
- 桌面与移动端均可用，键盘焦点可见，减少动效偏好得到尊重。

## 方案比较

1. **本地视频 + 可测试字幕核心（采用）**：浏览器 Object URL 播放用户文件，纯函数负责解析、校验和导出。零后端、隐私边界清楚，适合 GitHub Pages，也能覆盖项目清单中的“逐条对齐 + 预览”。
2. **只做字幕表格**：实现更快，但缺少真实画面和播放头联动，无法验证字幕是否贴合内容。
3. **自动语音识别工作流**：价值更高，但依赖模型/API、长任务队列与密钥，超出 59 号三级项目范围。

## 视觉方向

界面取材于实体剪辑台、场记纸和胶片边码，不使用泛化的深色视频编辑器。大面积为冷灰蓝设备面板，工作区域是略暖的校片纸，信号色只承担播放和告警。

- `bench #DCE3E6`：剪辑台机身
- `paper #F7F3E8`：字幕与校片纸
- `ink #18242E`：文字、边线和时间码
- `reel #275AA8`：播放头、选择和主操作
- `splice #EF5B3E`：切点、录入与错误
- `signal #D7E65A`：当前字幕与成功状态

标题使用 `Arial Narrow` / `Bahnschrift Condensed` 的窄体设备铭牌感，正文使用 `Segoe UI`，时间码与技术数据使用 `Cascadia Mono` / `Consolas`。签名元素是一条贯穿页面的“走片尺”：字幕以纸带片段落在刻度上，蓝色播放头像机械读头一样穿过视频、尺子和列表。页面只在播放头和当前字幕切换时使用克制动效。

## 架构与数据流

- `subtitle-core.js` 是无 DOM 依赖的 UMD 模块，负责时间码解析/格式化、SRT/VTT 解析、条目规范化、活动字幕选择、诊断、拆分和导出。
- `app.js` 管理视频 Object URL、草稿持久化、选中项、播放头与 DOM 渲染。视频 `timeupdate` 和 `requestAnimationFrame` 只更新必要读数。
- 时间轴按视频时长或字幕末尾自动缩放；字幕片段可点击定位，当前播放头由原生 range 输入提供键盘可访问的拖动能力。
- 草稿采用带版本的 localStorage 数据；损坏数据回退到示例字幕。视频始终仅由本次文件选择产生，刷新后要求重新选择。
- 文件导入限制为 2MB，字幕条目限制为 2,000 条，单条文字限制为 1,000 字符，以防意外大文件拖垮页面。

## 错误处理与验证

- 不支持的视频由浏览器 `error` 事件转为明确说明；旧 Object URL 在替换或离开时释放。
- 解析器忽略 BOM 与多余空行，支持 SRT 编号、省略编号、逗号/点毫秒和 VTT cue settings；无有效条目时拒绝覆盖当前草稿。
- 时间字段非法时保留编辑焦点并显示错误；重叠是警告，不阻止导出。
- Node 测试覆盖时间码、SRT/VTT、换行、HTML-like 文本、排序、重叠、活动字幕、拆分与双格式导出。
- 浏览器验证覆盖导入、视频预览、播放联动、编辑、快捷键、导出、刷新恢复和移动端无横向溢出。
