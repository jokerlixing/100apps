# #028 表情包搜索器 (Emoji Search)

中文关键词表情搜索：600+ 表情词典 + 分类浏览 + 收藏夹。

## 功能
- **中文搜索**：输入"开心/猫/哭/庆祝"等关键词，实时过滤匹配表情
- **24 个分类**：情绪/动物/食物/旅行/天气/工作/运动/音乐/节日…标签页切换
- **一键复制**：点击卡片复制表情（左上角"已复制"反馈）
- **收藏夹**：右键/双击/移动端长按收藏，★ 标签独立浏览
- **多关键词标注**：卡片底部显示表情所属分类

## 核心知识点：本地词典搜索
```
数据结构：DICT = {关键词: [emoji, ...]}
  600+ emoji 按语义分组，一个 emoji 可属多组

搜索 = 词典键包含匹配：
  Object.keys(DICT).filter(k => k.includes(q))
  → 展开对应表情数组去重
  
分层过滤：标签页（池）∩ 搜索（命中集）

Unicode 清洗：
  \p{Extended_Pictographic} 正则属性匹配
  过滤词典构建时误植的普通文本
```

## 交互设计
- 点击=复制，右键/双击/长按(600ms)=收藏——两种操作不打架
- 移动端 touchstart/touchend 计时长按，滑动取消
- hover 已包 @media(hover:hover)

## 技术栈
纯 HTML/CSS/JS 单文件，零依赖，离线可用（纯本地词典）。
