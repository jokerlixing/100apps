# #035 DRAW/35 随机分组工具

一个适合团建、课堂和工作坊现场使用的本地随机分组台。粘贴名单后可按组数或每组人数分配，分组结果支持锁定成员再洗牌和一键复制。打开 `index.html` 即可使用，无账号、无后端、无外部依赖。

## 功能

- **灵活名单导入**：支持换行、英文/中文逗号、分号和 Tab 分隔
- **自动清洗**：去除空白项并按名称忽略重复成员
- **两种分组方式**：按组数均衡分配，或限制每组最多人数
- **安全随机洗牌**：使用 `crypto.getRandomValues()` 驱动 Fisher–Yates 算法
- **锁定再洗牌**：点击成员票券锁定所在组，重新洗牌时只移动未锁定成员
- **结果摘要**：显示抽签轮次、组数、人数、平衡程度和锁定数量
- **快速复制**：复制单组或全部分组，包含编号和人数
- **二次确认清空**：避免现场误触导致名单丢失
- **本地持久化**：名单、设置、分组结果和锁定状态存入 localStorage
- **快捷键**：`Ctrl/⌘ + Enter` 直接抽签
- **响应式与可访问性**：桌面左右工作台、移动端上下布局、键盘焦点和 ARIA 状态

## 核心知识点：带锁定位置的重新洗牌

```text
现有分组 + 锁定成员
        ↓
先把锁定成员放回原组
        ↓
从名单中排除已经锁定的人
        ↓
安全随机打乱剩余成员
        ↓
按各组剩余空位依次填充
```

当名单、分组模式或目标人数发生变化时，旧锁定状态会自动清除，避免锁定成员超过新组容量。

## 分组规则

- 按组数：使用商和余数计算各组容量，人数差最多为 1
- 按每组人数：前面的组达到人数上限，最后一组接收余下成员
- 至少需要 2 位成员，最终必须产生至少 2 个组
- 重复名称按本地化小写形式判断，界面保留首次出现的写法

## 视觉设计

界面取材自运动会签到桌：淡紫蓝桌面、黄色名单夹板、珊瑚抽签按钮和多色分组公告板。每位成员是一张带虚线撕口的号码票，锁定操作表现为票券盖章，让“保留原组”在现场一眼可见。

## 技术栈

纯 HTML / CSS / JavaScript 单文件，无框架、无构建步骤、无网络请求。
