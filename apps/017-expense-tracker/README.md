# #017 记账本 (Expense Tracker)

L2 开篇之作：分类收支记录 + SVG 饼图统计 + 月度视图。

## 功能
- **记账表单**：支出/收入切换（分类各自独立）、金额、8+5 个分类、备注、日期
- **月度概览**：本月支出 / 收入 / 结余 三卡实时汇总
- **支出饼图**：SVG stroke-dasharray 圆弧拼接（无图表库），中心显示总额，图例带百分比
- **流水明细**：按日期倒序，分类图标+彩色边框，悬停删除（二次确认）
- **月份翻页**：‹ › 切换查看历史月份
- **数据持久化**：全部存 localStorage，不上传
- 金额框回车快速记账

## 核心知识点：数据驱动架构（L2 标志性升级）
```
单一数据源：txs 数组是唯一真相
    ↓
render() 全量重算三张视图（概览/饼图/流水）
    ↓
任何增删改 → save() + render() 两条命令收尾

对比 L1 的"改哪个 DOM 更新哪个"：
  数据驱动 = 永远不会出现视图不同步
  代价 = 全量重绘（这个量级毫无压力）
```

## 分类体系
支出：餐饮/交通/购物/居住/娱乐/医疗/学习/其他
收入：工资/奖金/理财/红包/其他

## 技术栈
纯 HTML/CSS/JS 单文件。饼图为手写 SVG（周长 = 2πr，分段 dasharray）。
