# #019 贪吃蛇 (Snake Game)

经典贪吃蛇游戏：方向键控制、吃食变长、撞墙撞己即结束，最高分持久化。

## 功能
- **键盘控制**：↑↓←→ / WASD 移动，空格暂停/开始，R 重开
- **移动端**：屏幕方向键（D-pad），自适应显示
- **计分系统**：吃一个食物 +10 分，最高分存 localStorage
- **动态难度**：每 50 分加速一档（stepMs -14），最高 5 档
- **渲染细节**：蛇头金色发光带眼睛（朝向感）、蛇身渐变、食物红色脉动
- **碰撞检测**：出界 + 咬身，防 180° 反向自杀
- **暂停/结束覆盖层**：毛玻璃效果

## 核心知识点：游戏循环（Game Loop）
```
rAF（requestAnimationFrame）驱动渲染帧
  ↓
accum 累加 deltaTime
  ↓ 每 stepMs 毫秒 tick 一次
游戏逻辑步进（移动+碰撞+吃食）
  ↓
draw() 全量重绘

固定步长设计优势：
  - 游戏速度稳定（不随帧率波动）
  - 可调难度（改 stepMs 即变速）
  - 逻辑与渲染解耦

输入缓冲：nextDir 缓存方向，tick 时才应用
  ——防"一帧内连按两键反向自杀"
```

## 细节
- 蛇身渐变：头(金色)→尾(暗绿)，长度越长色差越明显
- 蛇头眼睛：根据 dir 动态定位，朝向感
- 食物脉动：sin 函数 + 阴影模糊呼吸效果
- 防反向：setDir 时检查 d.x===-dir.x && d.y===-dir.y
- 食物生成避重叠：尝试最多 200 次不落在蛇身上

## 技术栈
纯 HTML/CSS/JS 单文件。Canvas 2D 绘制。
