# App 089 · LOOM/89 个人知识库设计

## 产品边界与方案选择

LOOM/89 面向需要把零散阅读、项目与思考笔记连成脉络的个人用户。它的单一任务是：让用户写下一则笔记，用 `[[双链]]` 建立关系，并能从搜索、反向链接和关系图中重新找到上下文。首版不引入登录、多人协作或远端数据库，所有内容默认只保存在当前浏览器，并提供完整 JSON 备份。

1. **本地优先静态应用（采用）**：GitHub Pages 直接可访问，双链、搜索、关系图和备份都在浏览器完成；隐私边界清楚，离线也能工作。
2. **带服务端同步的知识库**：可跨设备，但认证、冲突合并、数据库和部署成本会盖过双链知识库的核心体验。
3. **关系图优先的可视化画布**：视觉冲击强，但长文编辑和检索会退居次要，容易把知识工具做成只适合演示的图表。

## 架构、数据与核心交互

`knowledge-core.js` 是无 DOM 的领域层，负责笔记规范化、`[[标题]]` 提取、安全 Markdown 渲染、全文检索、反向链接、图数据、重命名链路更新及备份校验。`app.js` 负责界面状态与 `localStorage` 持久化；首次启动写入一组可删除的示例笔记。每则笔记包含稳定 ID、标题、正文、标签、创建和更新时间，不把用户输入拼入可执行 HTML。

左侧索引列提供全文搜索、标签筛选和按更新时间排序。中央工作台可在编辑与阅读间切换；输入 `[[` 时显示可选笔记，阅读态中的已解析双链可直接跳转，未解析双链可一键创建。右侧脉络栏显示当前笔记的出链、反向链接和局部关系；“打开星图”进入全库 SVG 关系图，节点可点击回到笔记。标题重命名时自动更新其他笔记中完全匹配的双链，避免静默断链。

删除使用二次确认；导入先完整校验再替换，错误文件不会覆盖当前数据。保存失败、导入失败和空搜索都有明确下一步。快捷键包括 `Ctrl/Cmd+K` 聚焦搜索、`Ctrl/Cmd+N` 新建、`Ctrl/Cmd+S` 保存当前草稿。

## 视觉系统与布局

界面取材自制图室与线装档案，而不是通用卡片仪表盘。色板为：**制图蓝** `#26345F`、**雾纸白** `#F2F5F7`、**节点珊瑚** `#F06A5D`、**索引青** `#2C7A78`、**铅芯黑** `#182033`、**网格银** `#CBD4DE`。标题使用 `Bahnschrift SemiCondensed` / `Arial Narrow`，正文使用 `Segoe UI` / `Microsoft YaHei`，路径、日期和快捷键使用 `Cascadia Mono` / `Consolas`。

标志性元素是贯穿编辑器与关系视图的“织线”：当前笔记的出链在页边显示成带方向的细线，打开星图时同一套线条展开为完整关系网络。其他表面保持平整、低圆角和清晰边线，让关系本身成为唯一视觉重音。

```text
┌ LOOM/89 ─ 知识索引 ─────── [新建] [导入] [导出] ┐
├──────────────┬──────────────────────┬──────────────┤
│ 搜索 / 标签  │ 标题 · 编辑/阅读     │ 当前脉络     │
│ 最近笔记     │ ┌──────────────────┐ │ 出链         │
│ · 笔记摘要   │ │ 正文与 [[双链]]  │ │ 反向链接     │
│ · 笔记摘要   │ │                  │ │ 局部星图     │
│              │ └──────────────────┘ │ [打开星图]   │
└──────────────┴──────────────────────┴──────────────┘
```

窄屏改为顶部工具栏、可横向滚动的笔记索引和单列编辑器，脉络栏折叠到正文下方。键盘焦点始终可见，关系图节点具备可访问名称，并遵守 `prefers-reduced-motion`。

## 验证标准

- Node 单元测试覆盖双链解析、安全渲染、搜索排序、反向链接、关系图、重命名更新和导入边界。
- UI 契约测试确认页面关键控件、无障碍标签、本地脚本和 README 入口完整。
- 浏览器烟雾测试覆盖新建、编辑、双链跳转、搜索、阅读预览、关系图、刷新持久化与移动端布局。
- 根追踪器登记 89 号最终名称、说明、GitHub Pages URL 和正式完成状态，并由追踪器测试锁定。
