# #039 CUT/39 短链接服务

一个面向独立创作者的本地短链接管理与点击统计工具。它把长网址送入“链路切片机”，生成好记的短别名，并在当前浏览器中管理点击记录与七日趋势。

直接打开 index.html 即可使用，无账号、无后端、无外部依赖。

## 功能

- **短签创建**：粘贴 http/https 地址并生成本地短链
- **自定义别名**：支持 3–24 位小写字母、数字和短横线，重复时给出明确提示
- **自动别名**：根据英文标题、域名和路径生成，并自动解决冲突
- **链接管理**：标题、标签、编辑、复制、跳转测试与二次确认删除
- **本地路由**：使用 `#go=<slug>` 打开跳转门，找到目标后记录一次点击
- **搜索筛选**：联合匹配标题、别名、目标地址、域名与标签
- **点击统计**：本地短签数、累计点击、今日点击、热门短签、七日趋势和点击排行
- **安全边界**：仅允许 http/https，用户文本统一转义，损坏存储自动回退
- **响应式与可访问性**：桌面/移动布局、语义表单、清晰键盘焦点和减少动态效果

## 静态托管边界

这个应用部署在 GitHub Pages，没有数据库或短域名后端：

1. 短签目录和点击事件保存在当前浏览器的 localStorage。
2. `#go=<slug>` 只有在保存过该别名的浏览器中才能解析。
3. 复制到另一台设备不会自动同步目标地址或统计数据。
4. 打开短链只进入本地跳转门，继续访问目标始终由用户主动触发。

界面在数据台和找不到短签的页面明确展示这一限制，不会把本地原型描述成云端服务。

## 数据结构

~~~javascript
{
  links: [
    {
      id,
      slug,
      url,
      title,
      tag,
      createdAt,
      clicks: [{ at, source }]
    }
  ]
}
~~~

## 视觉设计

界面取材自包裹分拣台：纸蓝色底板承载地址轨道，橙色刀口表示裁切动作，青柠色短签表示可用路由。链接卡片像带色标的包裹标签，首屏“链路切片机”是应用最有记忆点的交互。

## 技术栈

纯 HTML / CSS / JavaScript 单文件，无框架、无构建步骤、无网络请求。
